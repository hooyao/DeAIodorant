# 校准后的研究目标与证据计划

版本：`deaiodorant-target-discovery-1.6`。
依据：维护者在 2026-09-14 对项目目标和证据作出的澄清。这是当前研究优先级的记录；已完成实验的输入和结果保留原始版本。

最新执行检查点见 [HANDOVER.md](../HANDOVER.md)：[首轮篇章动作测量](routes/compact-refiner/reports/cognitive-move-pilot-v1.md)已完成36条记录，发现估算归属覆盖和槽位角色问题；[独立文章发现](routes/compact-refiner/reports/independent-media-discovery-v1.md)保存新候选及反例。下一步以记录契约1.1草案按文章隔离检验，不回改旧输出，不将已读新文当未见验证。文末的较早“下一步复筛”属于阶段记录，不应重复执行。

## 要解决的问题

改善 InfoQ 等媒体实际发布的完整中文文章中，读者感知到的机器式写作问题，同时保留事实、信息、限定、作者意图和有用细节。文章上下文和篇章结构都很重要。合成通知或新近通过 prompt 生成的合成文章，不能替代目标媒体的真实分布。

项目前半部分必须找出这种主观体验背后可重复观察的语言特征。研究开始前，不要求读者先提出形式化的特征定义：感受到的差异本身就是需要解释的观察。但特征弱或不明显的样本，无法帮助识别它几乎没有表现出的现象。在这样的材料上反复测试特征、改写或比较模型，不能解决抽样问题。

下游产品可以使用小型编辑模型、SFT、preference optimization，以及经过验证的 NLP reward 成分。这些方法不能替代前半部分的发现任务，也不能凭方法本身证明成功。GPU 训练继续暂缓。

## 当前由读者提供的强度参照

维护者已将 `https://post.smzdm.com/p/a70dm4ll/` 的完整 SMZDM Microduck 文章评为 `极其臭` 和 `恶臭`，并将此前提名的 Baidu 文章评为 `一般臭`。这是读者实际给出的强正例观察，并有一个较低强度参照，不是助手虚构的标签。保留原话，不要重复请求同一评分。两篇文章的来源、体裁、长度和呈现方式不同；一位读者对两篇文章的判断支持探索性发现，不构成已验证的强度模型。

[参照文章分析](routes/compact-refiner/reports/reader-anchor-feature-discovery-v1.md)将反复出现的表面风格与指代、支持关系问题分开。强烈正例文章中，字面 `而是` 的次数为零；必须结合上下文考虑隐含对比形式和反复出现的立场。没有改写任何原文，也没有将任何特征升级为 RL reward。发布者明确披露使用 AI，与读者判断是不同的证据，不能据此确定生成流程。

维护者明确指出，`而是` 仍然是强信号；在所给例子中，单独使用判断词也表达同样的纠正。标题中的 `先把买、搓、等三条路算明白` 也被直接指出令人反感。替换连接词不会消除底层修辞动作。下一步解释重点是[纠正框架假设](routes/compact-refiner/rhetorical-mechanism-hypothesis.md)，包括对比为何成立、语义关系、新信息和支持依据。仅仅扩充关键词清单，不能完成这项任务。

## 两个相连的目标：令人反感的信号与实际阅读缺陷

维护者用气味警示腐败食物的类比，解释臭味如何成为预期阅读困难的指示剂。这是读者自己的解释，不是实验已确立的心理机制。产品必须同时处理令人不适的表层或篇章信号，以及其背后的句子、指代或推理问题。去掉标记但留下破碎的说明，不算成功；修好结构却保留无必要的重复包装，也可能仍让读者不满意。

分别测量：信号频率和复现；谓词、论元与指代诊断；篇章支持关系与推进；实际阅读困难和偏好。不要将它们合并为未经验证的分数。中文并不要求每句话都显式具备主语、动词和宾语。合法省略、共享论元、不及物谓语和名词性谓语，都是简单“缺少 SVO”检测器必须面对的反例。

读者认为当前 Cowork 文章的 AI 臭味较弱，但难读且像翻译腔。这一感受不能确立其翻译来源，也说明信号计数、感受到的臭味和阅读困难不能作为可互换的标签。

此后，维护者否定了反复提交的 Cowork 阅读预览，认为它不适合作为具有鲜明中文 AI 写作特征的例子。它可能通过翻译继承上游英文 LLM 的问题，但这不提供所需的目标对照。该预览已撤回；对样本选择的否定不是 A/B 偏好，也不是可读性结果。不要以一般可读性目标重新提交 Cowork。已经完成的修复保留为工程记录。

当前前半部分的直接重点，是在真实完整中文文章中找到持续、明显的目标表现。原文语言或生成路径是解释背景，不是严重程度标签。直接中文标签、连接词计数高、孤立错字或难读的译文，都不足以单独确立这样的样本。处理译文的能力仍属于最终产品范围，但不能替代当前发现任务。

明确提出的构式家族包括 `不是……而是……`、`并非……而是……` 和其他 `而是` 形式。在强正例数据集完备之前，已授权并且有必要对现有时间 cohort 做有限的描述性计数。它检验出现次数的差异，不检验读者伤害或编辑效果。弱样本的限制不妨碍检查具体可观察特征；它限制的是对检查结论的夸大。

意义保留的边界继续有效：不能为了使段落显得连贯而编造缺失事实或没有支持的逻辑前提。如果无法根据文章实际包含的信息修复，就记录这个缺口。

## 翻译媒体与上游内容质量

维护者进一步强调，英文原文可能已经存在重复框架、信息增量不足和缺乏支持的推理，翻译又增加了中文措辞或指代缺陷。将其视为可能的分层问题路径，不能当成某篇文章已核实的创作历史，也不能当成翻译的普遍缺陷。

维护者明确否定此前一概排除译文的做法，并要求微调后的模型改善翻译成中文的文章。研究中保留中文原创、译文、混合或改编、来源未明四类 provenance 分层。各层采用相同的时间边界；仅含原创的视图用于对照或 sensitivity analysis，不能成为有用研究材料的定义。历史筛选结果保留原有范围。不得仅因文章是译文或难读就将其丢弃。

默认产品输入是完整中文文章。对应的外文原文可选，不能成为小模型的隐性前提。训练、validation 和最终评估必须明确覆盖中文译文，并分别报告偏好、意义保留和 fallback 结果。有真实原文对齐时，区分原文已有的缺陷、翻译引入或放大的缺陷、编辑新增内容，以及来源不明的情况。绝不预设英文原文质量良好，也不预设它由 LLM 写作或翻译。

除了语法，还要评估信息如何推进：命题重复、主张强于支持证据、框架冗余，以及读者为重建关系所需付出的努力。低 token entropy 或低 perplexity 本身都不能测量有用信息或读者收益。原文对齐和助手判断用于生成假设；产品评估仍以人工阅读结果和意义保留为准。

## 时间对照仍然有用

保留已确立的主要 cohort：

| Cohort | 发布日期 | 研究作用 |
|---|---|---|
| 历史基线 | 早于 2023-01-01 | 以人类创作为主的时期中的写作 |
| 过渡期 | 2023-01-01 至 2025-06-30 | 单独的诊断区间，不纳入主要对照 |
| 普及后 cohort | 2025-07-01 及以后 | 在维护者观察到的风格大致变化时间之后，主要搜索目标的区间 |

2025 年 7 月边界来自维护者的观察和既有抽样政策，不是当前数据已经统计确立的断点。不得看过结果后悄悄重新调整。任何 change-point analysis 都需要单独冻结计划，并具备足够的时间覆盖。

日期提供有用的抽样先验，不提供文档级作者身份或臭味标签。早期自动生成和旧页面后续更新，使个体作者身份无法得到绝对保证。较晚的文章可以写得好，较早的文章也可以写得差。保留发布、更新和采集来源信息，不训练人类与 AI 作者分类器。

## 要保留和复用的成果

- 已采集的媒体正文、稳定 ID、canonical URL、时间戳、来源 metadata、质量与传播可见性信号，以及精确和近似重复处理。
- 翻译或外文编译证据及旧排除决定。只在新版本中将其重新解释为 provenance 分层和仅含原创的对照；相互矛盾的 metadata 绝不能悄悄被当作原创证明。
- 现有 NLP 实现、已冻结的特征配置、按来源分层的分析，以及已记录的负面结果。
- 每一条原始人工评论、评分和 A/B 选择，不回溯改写，也不转换为更强的标签。
- API 客户端、请求与缓存 provenance、成本控制、完整原文 hash、呈现映射、操作重放和意义保留检查。
- 合成 CR-001 fixture 及结果，作为工程对照和针对其实际任务分布的有限行为诊断。

旧的低信号实验仍是有严格适用范围的历史证据。暂停继续这些实验，不意味着丢弃采集基础设施、时间 cohort、特征发现这一目标，或整个语料库。

## 对历史标注解释的纠正

维护者指出，此前的标注样本不具备足够强烈或明显的目标特征，那些实验没有实质回答目标问题。因此，不能将此前的局部抱怨或编辑偏好当成新实验中已经确认的严重正例。保留旧局部评论与当前评价之间的张力，不抹除任何一方。

三组 CR-001 预览偏好属于普通的定性编辑反馈：其中一组包含内容差异顾虑，一组没有说明偏好强度，另一组明确只有轻微差别。读者认为所展示的配对中没有明显臭味。这些选择和 agent 的意义保留判断，都不能确立去臭效果、已验证的 reward 或训练验收。

## 修订后的证据顺序

1. **保留采集基础。** 审查可用来源、时间组、提取保真度、排除情况、缺失材料和此前暴露情况。保留完整文章及任何实质相关的图、图注和链接。
2. **改善真实媒体中的目标覆盖。** 在合适的时间和来源分层中搜索候选强弱印象。agent 或本地检查可以提名案例与证据，但必须保留不确定性和反例。不要通过 prompt 或编辑制造正例。
3. **建立可感知的对照。** 只有目标边界确实需要维护者判断时，才使用少量具体的人工比较。不要要求读者标注句法或推导特征，也不要在大批标注中反复提交差异不明显的段落。
4. **在明确声明的 development 数据上发现特征。** 比较可观察构式、篇章推进、复现和局部聚集，并尽可能控制来源、主题、格式、长度、翻译和传播可见性。时间差异与主观强度是两个不同维度。
5. **检验可重复性与竞争性解释。** 使用独立文档、反例、来源及体裁 sensitivity analysis、适当考虑聚类的抽样，以及可实施且事先规定的检验族。富集强弱样本支持特征发现，不能估计自然 prevalence。
6. **验证编辑干预。** 只有相关现象得到确立后，才冻结范围有限的操作。呈现整篇文章的上下文，同时要求有用的读者偏好和意义保留。
7. **之后再选择训练方法。** 收集经过适当复核的编辑与偏好数据。SFT、DPO 和 online RL 仍分别取决于自身证据和算力要求。

不要要求尚未发现的特征先筛出自身的第一批正例。初始感知比较和原文检查可以建立暂定对照；由此得到的特征必须接受独立材料检验。反过来，也不能为了回避真正需要决策的节点，就把 agent 的印象叫作已确认的人工标签。

## 当前状态

在此前 1.1 版检查点，没有开始媒体编辑或 SFT。提出的合成 CR-002 文章任务保留但尚未执行，也不是下一项主要实验。当前原文审计只能确立文本身份和呈现限制，不能据此将已检查文章判为强正例。

已完成且有用的检查包括[媒体清单](routes/compact-refiner/reports/media-development-inventory.md)、[原文完整性审计](routes/compact-refiner/reports/media-source-completeness-v1.md)和[合成生成链审计](routes/compact-refiner/reports/cr001-generation-chain-audit.md)。此前采集的全部正文和反馈保持完整。

此后，一次新的[有限范围真实媒体暂存与校准](routes/compact-refiner/reports/media-contrast-calibration-v1.md)保存了 24 个固定公共响应，获得 20 篇非空文本，在确定性翻译排除后剩余 16 篇。两次独立全文复核提名了一篇文章；维护者随后认为它 AI 臭味较弱，但难读且像翻译腔。它仍未正式准入，也不是已确认的强正例。单独要求的[对比构式家族统计](routes/compact-refiner/reports/ershi-cohort-statistics-v1.md)现已提供精确的描述性信号测量，不是效果或训练结果。对该文章而言，原创性仍是单独且未解决的准入项。

后续的[整篇文章审计](routes/compact-refiner/reports/contrast-context-audit-v1.md)和 CPU parser 可行性检查已经完成。新的全媒体统计视图保留译文，采用 provenance 分层，并明确纠正旧筛选计数。[有限范围的修复开发](routes/compact-refiner/media-repair-development.md)现在准备完整的、仅依赖中文输入的文章修改提案，其中包括一篇翻译访谈。这些属于已暴露的 development 来源，不是新的 validation，也不是人工确认的强臭味样本。SFT 尚未启动。

这些提案和意义保留复核现已完成，但 Cowork 读者任务因[样本不匹配而撤回](routes/compact-refiner/reports/cowork-preview-withdrawal.md)。没有收到读者偏好。下一步是[目标覆盖重新筛查](routes/compact-refiner/target-coverage-rescreen.md)，不自动改写、不用其他读者任务替换，也不导出训练数据。
