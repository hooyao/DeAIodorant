# 篇章动作测量工程实验 1.0

日期：2026-09-14。范围：已暴露的两篇文章、六个开发案例。冻结发生在首次盲标注之前，时间和 SHA256 见运行目录的 `freeze.json`。

## 问题与单位

检验八字段分析在等义改写下能否保持核心命题与关系，并随语义变化而变化。另检查是否臆造先前观点、丢失限定、混淆作者断言与引述，以及把有用纠正或正常解释判成错误。

真实来源只有两篇。六个案例、18 个条件、36 次模型标注均不是新增独立文章或人工样本。该实验不估计自然发生率，不计算显著性或统计功效，不提供臭味总分，不认证编辑效果。

## 条件与预检查

每例包含原文、等义变体和单一主要语义维度改变。独立设计 Agent 读完整文章提出变体，主 Agent 在标注前复核所有修改及预期差异。设计者和复核者均知道旧分析，不能充当盲标注者。预期是待复核的工程断言，不是人类 gold。

等义操纵要求实体、数量、否定、范围、情态、归属和核心关系保持；连接词及呈现可变化，不要求风格印象不变。语义操纵尽可能覆盖不同维度；任何无法消除的上下文矛盾或多维度变化必须在设计中单列，不在结果出来后悄悄修改操纵。源文及历史记录不变，变体只存在于新目录。

预检查后的六项改变依次是议程范围、Jetson排除状态、核心价值集合、估算归属、例证次数、因果情态。M05只是数量字段覆盖探针：合理压缩导致未提及次数时记为未覆盖，不计核心失败，也不能计敏感性成功。M02伴随主要平台与附加设备的范围变化，M04伴随来源背景撤去，M06伴随句界及回指变化；结果必须连同这些构造限制解释。M01标题收窄但正文仍有额外内容，不自动构成逻辑矛盾或阅读缺陷。

## 分配与隔离

固定 seed `20260914`。六个新建 Astra 同系列任务，每任务六个案例，每个焦点只见一种条件；三个循环分配覆盖所有条件，独立重复两组，并随机化任务内顺序。packet 使用无意义 ID，隐藏旧标签、历史标注、条件名称、配对和预期答案。仅提供完整文章的文字视图、待分析 block 及中性字段说明。

两个重复组来自同一模型家族，不能当独立人工复核。不同案例共享全文，任务内可能从另一个焦点的上下文见到相邻原始段落；循环分配和随机顺序仅减轻顺序效应，不能消除这种 carryover。因此即使全部通过，也只能支持本次有全文上下文的工程可行性。后续新文章仍需按文章隔离。

盲任务只读其分配材料，适用仓库约束通过中性说明传入；包含已知标签的交接及指南不传给标注任务。这是维护者接受的“隐藏旧标注和强弱评价”的实现。每任务如实记录自身身份、暴露情况和阅读范围。正文中的来源品牌无法彻底遮蔽；不声称双盲或消除训练数据记忆。

## 判定与继续条件

首先逐条核验引文与当前 packet 精确对应、八字段齐全、分配完整及冻结 hash。格式或引文错误作为首次输出失败保留，不静默修复；若补交，只能另存版本并单列。

随后主 Agent 对照源文和冻结预期，分别报告：

- 同条件两个任务在动作划分、命题范围、关系及依据上的一致、可兼容差异与实质冲突。
- 六组等义对照是否保持预先指定的核心内容；正常呈现差异不判失败。
- 六组语义改变是否反映目标差异；遗漏、错误回填旧原文与过度推断分别记录。
- 支持不足、文字未说明、事实错误及正常解释有没有被混淆；有用信息是否得到保留。

各例用 `supported`、`mixed`、`failed`、`indeterminate` 描述，保留逐例证据与复核解释；不把不同层级分母混合成“准确率”。语义一致与语义正确分别审查。分段边界允许合理分歧，不要求逐字改述一致。

若任何案例出现未解决的核心命题、否定、范围、归属或关系实质冲突，不宣布该框架已可用。最多提出一轮明确的框架修订，后续在新版本和未见文章上检验，不反复调试这18份材料直到通过。全数没有未解决关键错误时，也只允许进入新文章复现与有限编辑可行性准备；读者效果仍需要独立评价。

## 并行真实文章发现

另设最多8次公开搜索、6篇全文读取的发现批次，优先同来源同体裁的硬件购买指南/DIY成本文章。保留来源、全文完整性、日期、原创/翻译等来源类型和未找到对照的结果。助手只提名，不新增人工严重程度标签。旧87候选和validation reserve保持隔离。

这批已经阅读全文、用于定性挑选的文章属于新 discovery，不能事后标为未见验证集。后续文章隔离验证需另行预先固定 URL/抽样规则，再执行标注；不足时明确留待后续。

## 运行、成本与产物

生成与核验使用 Python 标准库。模型推理使用当前 Codex Astra 子任务，不调用外部强模型 API，不使用 GPU；本环境实际推理成本未单独提供，不能报告为零成本。新公开来源的服务成本/授权状态由发现批次记录。现存第三方文本只用于已授权研究，新增训练或再分发权利未核实。

```powershell
python experiments/cognitive_move_pilot.py prepare --design data/local/cognitive-move-pilot-v1/reviewed-design.json --output data/local/cognitive-move-pilot-v1/run
python experiments/cognitive_move_pilot.py verify --run data/local/cognitive-move-pilot-v1/run
```

生成器拒绝覆盖已有目录。`design.json`、`key.json`、18份完整 packet、六份分配和源文件身份在首次标注前冻结；首次回答单独保存。结果报告与来源发现报告使用中文，原文保持原样。API/认证失败或来源访问限制不重试绕过；停止受影响批次并记录。
