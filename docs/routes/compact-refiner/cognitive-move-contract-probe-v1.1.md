# 篇章动作契约 1.1：文章隔离开发检验

日期：2026-09-15。实验版本：`cognitive-move-contract-probe-1.0`。使用[记录契约 1.1 草案](cognitive-move-record-contract-v1.1.md)，不修改旧 18 个 packet、36 条回答或历史标签。

## 问题与范围

检查否定对象／条件基线、所选命题的提出者与报道者、读者证据指向三个维度，在新的自然文章中能否得到可核查的记录。同时要求给出全文动作位置图和重复关系，避免只改 schema 而不解释文章中反复发生了什么。

本轮只测 1.1，每篇两次单独启动的 Astra 标注，不与旧 schema 做效果比较。不估计一般准确率、自然发生率、时间效应或读者收益，不训练、不构造 reward、不准备改写。

## 读取前选择

从已暴露的上一轮搜索结果中，仅依据标题、URL、搜索日期与主题说明固定四篇未在该轮阅读全文的 SMZDM 文章。选择记录及时间在 `data/local/cognitive-move-contract-probe-v1/selections.json`。不新增付费搜索，不以字面连接词计数选样，不预判人工严重程度。前后期、DIY 讨论和技术说明之间仍有体裁差异，不能称为匹配对照。

固定四次文章 GET 和一次 robots GET，不重试、不替补；访问限制或正文不完整按原样记录。搜索日期仅为元数据，真实发布日期另按页面核验。译文或来源未明不排除；正文、图片和上游来源的读取范围分别记录。

## 标注前冻结

先保存全部请求、原始 HTML、正文视图、blocks、图像引用及完整性限制。Root 全文复核提取覆盖，并建立不提供给标注者的自然检验机会清单：实际否定、条件分支、显式外部来源、作者判断、读者态度及潜在媒体支持。清单可写“该维度无机会”，不因缺机会追加文章。

随后冻结 packet、说明、生成器、来源 hash 和分配。一次任务只读一篇文章，分别绘制简短动作位置图，选择最多四个详细动作；优先覆盖不同角色和全文重复位置，说明未覆盖内容。不强制填满四个案例，也不强制存在错误。

## 隔离及暴露

每篇使用两个 fresh subagent，`fork_turns=none`，不复用已标其他文章的任务，不向其提供另一回答、机会清单或历史标注。只读指定 packet 与说明，首次回答独占保存。

保留原 AGENTS，不临时移除指南。自动注入内容包含项目假设与旧锚点评价；新文章没有既有人工标签，但不能称为双盲、独立模型或严格盲法。分别记录启动上下文、实际读文件、任务身份和暴露情况。共享文件系统不是强制隔离，自报须结合工具轨迹核查。精确 backend 不可知时如实写 `unknown`。

如果读取对方输出、其他文章或预期答案，保存记录并排除受影响回答；重做必须另开任务和版本，不能覆盖首次输出。

## 核心判定

`negated_proposition` 非空只表示有被否定对象，不等于发生一次认知纠正。应联合动作、关系和上下文判断。原文声称“很多人认为”只支持作者如此报道，不能认证读者实际持有该信念。

| 维度 | 可接受记录 | 关键失败／未覆盖 |
|---|---|---|
| 否定及条件角色 | 保留否定命题和范围，持有者独立；普通条件放 comparands | 因没有持有者删除否定对象；从条件基线补造误解 |
| 命题归属 | 所选估算、外部说法及作者后续判断分别绑定，保留其性质 | 遗漏提出者、跨命题串用人物、把报道者当估算者 |
| 读者证据 | 绑定具体态度或判断及报道层级 | 将等待意向扩大为价格／技术信念；将作者泛称当读者实测 |
| 无证据 | 空值与解释一致，保留未知 | 没有正向机会却凭空值稳定声称绑定能力已通过 |
| 焦点与复现 | 位置图和详细记录可对齐，保留价值与反例 | 只比较重合焦点、丢弃检测分歧，或遗漏唯一明确来源链 |
| 支持状态 | 区分文字缺失、潜在图表、合理省略和未核实 | 把未读图片／上游材料当不存在，或把未核实当错误 |

Root 按原文逐命题审查，先对齐选择位置，再看解释一致性；两份模型一致不等于正确。格式与引文检查独立报告。合理分段、措辞差异与实质冲突分开；没有选中某动作单列为覆盖问题，不能当语义通过或失败。

维度至少在两篇不同文章出现可检查机会，且没有未解决的关键错误时，才可作“暂支持”的开发判断。这是防止单例过度解释的工作门槛，不是统计验收线。没有机会记为未覆盖。

## 停止与后续

完成固定的可读取文章，不因首个失败丢弃其余固定样本。出现任何未解决的核心否定、归属或证据指向错误，就停止将相应字段升级为自动特征或训练输入，不通过增加自由文字或反复修改同一输出刷通过。

若字段可用但没有具体的持续动作与读者成本假设，则特征发现结论仍为空。只有可核查的实际语言现象和反例积累后，才提出后续文章复现或编辑干预。所有文章本轮被阅读后均为已暴露 development，不再作为未见验证材料。

## 成本与产物

只用公开网页的有限读取、Python 本地处理及当前环境 Astra subagent，不调用 OpenRouter 或外部强模型，不需要 GPU。网页请求不是收费模型推理；本环境任务的独立费用未知，不报告零成本。正文保留来源和权利声明，不默认获得额外训练许可。

新目录保存选择、请求、原文、机会清单、冻结输入、首次回答、机械核验、逐例裁定及中文报告。历史数据保持原样。新输出以独占创建为默认，后续修订另存版本。
