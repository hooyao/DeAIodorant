# 前瞻性媒体 provenance 扩展

Protocol：`media-provenance-extension-1.0`。日期：2026-09-14。
目标依据：`deaiodorant-target-discovery-1.3`。

这是新的有限采集与描述性诊断扩展，不是代表性语料库、读者研究、意义评估或训练集。任何新文章 GET 前，冻结本 protocol、实现、输入、身份和精确选样。此前全部采集与修复产物保持不变。

## 抽样与受保护身份

只使用此前抓取的公开 InfoQ sitemap index_1（预期后期）和 index_3（预期前期），按旧请求 hash 核验。这些抽样框不含文章日期。不要从 sitemap 位置、最后修改时间或预期 cohort 推断发布日。选样前和抓取开始时各刷新一次公开 robots.txt；更严格的政策可以减少尝试，但不能触发替换选样。

新 seed 为 `media-provenance-extension-v1-20260914`。每个预期抽样框在身份、跨框重复与 robots 排除后，按 SHA-256(seed + '-' + cohort + NUL + URL) 对 canonical HTTPS `www.infoq.cn/article/` URL 排序。每框恰好选 12 个，不共享 URL，也不补位。上限 24 次文章 GET，不重试。抓取前以仅含 metadata 的检查确认冻结配额和排除。

使用旧的仅含身份的排除映射与 benchmark 身份导出；核实所列来源 hash，不展示标签或正文。排除所有此前暂存选样和尝试过的文章，包括抓取失败者。冻结受保护数据集和旧暂存正文 hash，供后续机械 `ExclusionIndex` 检查。已知标注与 benchmark 身份继续排除；已暴露 benchmark 结果不影响选样或诊断。

## 公开访问与抓取

复用现有 `BoundedClient`、`robot_parser`、`robot_delay` 和 `extract_candidate` 实现，不修改它们。已标明研究身份的 user agent 保持不变。请求使用未经认证的普通公开 GET，禁用环境凭据，使用新 session，不跟随重定向，不用隐藏 API、cookie，也不下载引用媒体。遵守 robots，每次请求完成后至少等待两秒。遇到 429、Retry-After、认证或拒绝访问响应、明确属于非文章访问挑战的标题、响应大小上限或网络异常即停止。不绕过限制。保留每个响应、错误类别、部分抓取、未尝试选样和停止原因。不重试，也不自动恢复。

私下归档完整 HTML、规范化中文正文、段落映射、内嵌发布和更新时间、采集时间、canonical 链接及媒体引用。公开报告仅含聚合 metadata。发布 cohort 为早于 2023-01-01，以及 2025-07-01 或之后；过渡区间单独处理。若 UTC 与 Asia-Shanghai 导致边界归属不同，保持为歧义。日期缺失、空正文、提取失败、canonical 不匹配和时期错误均保留为结果。时期错误的抓取可以计入其实际且无歧义的 cohort，但必须明确报告不匹配。

## Provenance 与重复保护

保留译文与改编文章。历史提取器的翻译排除存为旧决定，不成为新的研究排除。两个时期应用相同证据规则：

- `mixed_adapted`：现有外媒实录证据，或现有直接翻译表达匹配中包含 `编译`。
- `translated`：显式译者字段，或现有直接表达匹配包含 `译自`、`翻译`、`译者`，但第一条优先。
- `unresolved`：所有其他情况，包括较弱的旧外文来源证据；另行保留这些证据。

这些是声明或证据分层，不是已核实的生产历史。缺少证据不认证中文原创；本自动扩展不作中文原创认证。外文姓名、链接、难读和信号次数都不决定 provenance。仅含原创的研究仍是未来需充分证据支持的对照，绝不是全局准入规则。

计算诊断前，将正文先与固定的旧 pilot、smoke、benchmark 数据集路径及旧暂存正文机械比较，再与固定批次内更早记录比较。使用现有阈值 0.9 的 `ExclusionIndex`，包括其已有长度、simhash 和 shingle 规则。索引只接收身份与内容字段；受保护标签、正文或结果不进入 prompt 或报告。保留匹配与缺失情况。该启发式方法不能证明语义独立。重复抓取继续归档，但不计入唯一文档诊断组。

## 冻结的诊断与解释

使用 `reading_burden.py` 中精确的字面 `而是` 与 CJK 正则表达式，不作前缀家族或语义分类。统计完整抓取正文，包括引述和保留的提取换行。只使用现有 `contrast_context_audit.concentration` 函数，窗口为 500 和 1000 个 CJK 字符。保留零计数文章。观察批次后，不调整窗口、阈值、子集或指标。

私下逐篇报告字面次数、CJK 数量、每 1,000 和 10,000 个 CJK 的频率，以及两个固定聚集结果。公开按实际 cohort、来源和 provenance 聚合，包含文档数、零计数文档数、总 CJK、总次数、合并频率和聚集计数分布。另报预期到实际 cohort 表、失败、排除、缺失传播可见性字段和发布时间范围。不设长度或可读性门槛。

这些来自现有抽样框、规模小且未匹配的结果属于探索性复现。来源、主题、体裁、长度和传播可见性未联合匹配；当前传播可见性受文章年龄混杂；provenance 规则可能漏证据；文本抓取遗漏未检查媒体。频率既不是时间因果效应，也不是总体估计，不表示作者身份或读者反感的严重程度。不涉及 LLM API、GPU、模型训练、人工臭味标签或意义标签。
