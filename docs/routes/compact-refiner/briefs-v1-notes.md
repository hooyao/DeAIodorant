## 状态与解释

文件含 24 项专门撰写的虚构任务说明，[CR-001](first-batch.md) 指定的四种体裁各六项。每项拥有独立 task-group ID、主题和事实包。这是构造 fixture，不是抽样出版物或自然写作模式 prevalence 的证据。每个实体、测量、事件和情境均虚构。构造时没有使用历史语料、旧预留集、封存测试、真实个人信息或外部原文。

事实包、必需事实陈述和风险笔记由 agent 撰写，**不是独立人工 gold 标签**、读者判断或语义保留证明。来源草稿仍须检查一致性；后续编辑必须保留其实际来源，不能将事实包当成添加来源缺失信息的许可。人工接受与偏好门槛仍独立。

全部任务要求普通中文行文，300-600 个汉字。没有任务要求差草稿、目标臭味标记、特定 NLP 分数或可识别模型风格。要求的受众和语气属于合法写作要求。保留有效且已经写好的草稿与不修改结果。

Fixture 是数据集落地的编写输入，尚不是完整 `briefs.jsonl` 数据集产物：数据集版本、创建时间、使用权证据和 canonical 逐条 hash 由 materializer 按[数据约定](data-contract.md)添加。生成任何版本前，全部 24 组必须分配到 development。衍生文本不产生新独立组。

## 构造选择与边界

每个事实包提供完整、紧凑的虚构事实集合。`required_facts` 数组对相同事实给出英文审计描述，不增加额外事实要求。这些陈述和 ID 是审计 metadata，不进入普通生成和编辑输入。`protected_literals` 提供有限字面筛查，主要针对名称、数量和状态标签。数字保留但主语或分母变化，仍可能语义失败；同一数量的表面写法变化需要解释，不能自动认证。

两句精确锁定句分别属于任务 19、20，也都出现在对应事实包中，生成指令都要求精确保留。其他来源措辞在语义保留前提下可编辑；字面列表为空不表示事实可选。通过共享只读上下文，事实包所有事实都明确在范围内。

事实包含 208-268 个 Unicode code point，其中 176-225 个 CJK 字符。它们是紧凑事实包，不是完成后的目标段落。行文长度目标不要求新增事实或泛泛框架来填充。下游长度处理须与来源事实一致性独立报告；不要仅因有效草稿已清楚或没有候选模式而悄悄重新生成。

样本有意覆盖条件、例外、测量限制、归属和未解决决策，因此相对未知部署分布，显式意义保留挑战被过度呈现。社区、文化和工作场景较多。不声称主题代表性，也不测试长篇叙事、个人文学风格、高风险建议或开放事实生成。通用上下文句和纯行文格式是共享指令，底层事件、事实关系和工作流分别构造。表面不同本身不证明统计独立或未来泛化。
