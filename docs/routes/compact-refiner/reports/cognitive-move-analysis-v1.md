# 解释与纠正篇章动作的分析示例

日期：2026-09-14。Protocol：`cognitive-move-analysis-1.0`。
状态：六个关联原文的分析案例；没有自动语义检测器、质量分数、读者干预或训练结果。

## 操作性定义

依据明确的原文证据，描述某个文本片段如何改变对主题的说明。不要推断读者实际持有的先前看法。确定核心动作，并将其与支持证据、后续总结和之后的动作区分开。一个段落可以包含多个动作，一个动作也可以依赖其他段落中的证据。六个案例是带上下文的分析材料，不意味着每个完整段落都是一个不可再分的原子单元。

| 记录组成 | 回答的问题 |
|---|---|
| 当前讨论的问题（question under discussion） | 这个片段处理什么问题？原文明说了该问题，还是由分析者重构？ |
| 先前或被否定的说法 A | 什么主张被否定或修正？它在此前出现、此处引入、来自引述，还是来源未知？A 可以不存在。 |
| 主张或承诺的内容 B | 提供了什么事实、解释、限定、价值重点或组织方式？ |
| 关系 R | A 与 B 是同一维度上的备选项、可兼容的不同维度、范围限定、因果解释，还是其他关系？ |
| 依据与推理连接 E/W（grounds and warrant） | 哪个原文片段支持 B？原文实际给出了什么连接，将证据与 B 联系起来？ |
| 信息更新 | 哪些内容变得更具体或组织得更清楚？这是有用的回顾、价值优先级，还是更强的外推？ |
| 立场与复现 | 叙述者如何表达确定性、纠正、权威或引导？该动作在哪里再次出现？ |

分析描述明确属于改述，不是原文引述。所有原文证据都保留文本视图标识、DOM block、精确引文和 Unicode offset。内容及关系评估与风格评估分别记录。

## 六个分析案例

| 案例 | 核心动作 | 内容及关系观察 | 风格观察与限制 |
|---|---|---|---|
| M01：SMZDM 标题 | 议程设置 | 不要求存在被否定的 A。正文三个部分落实了路线的组织方式；这些部分的存在不能证明全部成本都已说清。 | 维护者已经明确表达对标题措辞的反感。其成因和编辑后的反应仍然未知。 |
| M02：机载硬件 | 具体纠正 | Jetson 与 RK3566 对应同一个平台位置。文章给出具体板卡和部署上下文。没有确立读者原先相信什么。 | 读者将此构式认定为强信号。必须保留有用的技术内容；不推断该单元的数值严重程度。 |
| M03：产品价值 | 受用途条件约束的价值强调 | 玩具乐趣和学习基础设施可以共存。`核心` 一词与学习条件，使优先级强调成为一种合理解读。市场独占性是另一个主张，缺少对应的比较证据。 | 纠正式呈现可能重复，但未必构成形式上的 false dichotomy。 |
| M04：DIY 与复刻成本 | 两次连续推断 | 带限定的零售成本估算变成了更宽泛的省钱结论；随后比较对象转向逆向工程后的商业复刻。配置、已有零件、地域和规模并未保持一致。 | 确定性的判断可能超出原文承认的不确定性；尚未证明实际成本命题为假。 |
| M05：缓存机制 | 解释 | 不需要 A。复用保留的计算结果，将重叠上下文与减少重复工作联系起来；实现范围仍经过简化。 | 解释有用，并不要求它对每位读者都是新知识。戏剧化措辞另行观察。 |
| M06：Apple 类比 | 因果替换与迁移 | 结果数据伴随一个合理的平台机制，但不能单独确立因果优先性、先发地位或向 Agent 基础设施迁移的适用性。 | 果断的纠正式表述可能使尚未定论的因果假设显得更确定；保留后文带条件的结论。 |

M04 说明了这种分析为何比连接词计数提供更多信息。标注保留估算限定，指出更强的结论，定位下一段中明确的回指，并说明比较范围发生了什么变化。问题在于推理连接没有交代充分；识别它不依赖某个特定连接词。

M01 和 M02 同样是重要的对照。令人反感的标题可以组织文章，读者指出的纠正构式也可以增加真实信息。如果仅因整篇文章被评为严重，就强行将两者归入内容失败，这套框架就会陷入循环论证。

## 修订与原文检查

分析者的初版将六组材料关联到 43 处精确原文片段引用。主 agent 复核要求两项纠正：保留已经给出的标题局部反馈；区分核心动作、支持材料与后续动作。1.1 版保留原版，并显式增加核心位置、上下文动作，以及 M04 的两次连续推断。

当前产物包含 80 处已验证的片段引用，对应 58 个不同片段，分析者检查了 16 个输入 hash。主 agent 的独立脚本检查六个案例 ID、必填字段、原文字符串精确匹配、文本视图及 block 边界，以及 protocol 和记录标识。这些计数代表证据链接，不代表独立案例、测得的准确率或读者判断。语义解释仍是可复核的助手标注，保留未知项与其他合理解释。

## 实际计算路径

传统 NLP 可以定位候选分句、实体、否定、情态、指代表达和复现。现有词汇及 UD 探针不能被升级为证明两个主张处于同一维度、或证据支持某个结论的方法。这些才是困难的语义步骤。

一个有限范围的原型可以用强模型生成这些关联证据的记录，再通过独立复核质疑范围、归属和臆造的被否定说法。信任输出之前，先测试 paraphrase invariance 和对意义变化的敏感性：仅改变连接词时，应保留核心动作；改变极性、量化、范围或关系时，分析应反映变化。本次工作不声称自动模型已通过这些测试。

只有标注可靠性得到支持后，才应通过文章级分布和文章内部编辑实验检验假设。分别测量纠正频率、证据与主张的差距、反复出现的立场。不要臆造加权总分，也不要将其称为 RL reward。解释性标注听起来合理，本身不能验证一个特征。

## 产物

私有目录：`data/local/cognitive-move-analysis-v1/`。

- `units.json`：保持不变的初次标注。
- `units-v1.1.json`：修订后的核心位置、上下文及已有人工证据。
- `validation.json` 和 `validation-v1.1.json`：精确关联检查。
- `validate_units.py` 和 `validate_units_v1_1.py`：上述检查的复现脚本，保护已有输出不被覆盖。

这些分析示例没有修改原文、先前反馈、benchmark 或特征配置，也没有使用外部 API、GPU、改写文章或新增读者问题。
