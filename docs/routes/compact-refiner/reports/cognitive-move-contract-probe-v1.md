# 篇章动作契约 1.1：四篇新文章的开发结果

日期：2026-09-15。依据：[冻结实验协议](../cognitive-move-contract-probe-v1.1.md)。产物：`data/local/cognitive-move-contract-probe-v1/`。

本轮能把多种自然文本中的“谁说的、适用什么条件、凭什么得出结论”关联到原文，但 **1.1 的字段仍不能直接变成自动计数或 reward**。明确来源的绑定大多可审查；当前叙述者与更早原始出处、暗示预期与否定对象仍有编码分歧。一处覆盖说明还把版本发布时间的疑问扩大成了等待意向。

## 实际完成

在读取正文前，从上一轮已暴露搜索结果的标题和 URL 固定四篇，不补样。执行一次 robots GET、四次文章 GET，均成功；没有重试、新付费搜索、外部 LLM 或 GPU。搜索日期与页面日期有差异，最终使用页面证据。

| 文章 | 页面日期 | 文字／blocks | 主要自然检验机会 |
|---|---|---|---|
| n01：《亡灵遗产》版本指南 | 2026-08-31 | 3,255／26 | 下载页、玩家反馈、作者配置参考线及条件建议 |
| n02：Seedance 2.0 功能说明 | 2026-02-12 | 977／14 | 未署名“据实测”、平台限制、行业意义与行动建议 |
| n03：DIY 礼物讨论 | 2016-12-22 | 3,814／35 | 小伙伴观点、评论经历、作者调侃、站内引用卡片与条件分支 |
| n04：装修和 DIY 细节 | 2014-11-04 | 5,745／175 | 外部作者、父母和本人判断，空间条件，以及作者自身评价改变 |

合计 13,791 字符、250 blocks。全文文字视图全部保存；121 项图片／媒体引用未读取像素，29 条引用记录未核验上游。n03 的 17 个 `dir` 块是站内文章预览卡，保留其标题、截断摘要、作者和拼接的互动数字，不能将其当作单一作者连续正文。n02 来自同一公开响应内的七个结构化组件，没有追加隐藏接口请求。

这四篇与已暴露五篇发现文、Microduck 和 Baidu 锚点没有规范化后全文相同者；5-gram Jaccard 仅用于重叠诊断，没有设置阈值或当作风格分数。未打开旧保留集；这不是与所有历史语料完全独立的证明，也不是匹配的前后时间比较。

输入及机会清单在标注前冻结。八个 fresh subagent 各只分配一篇，共得到八份回答、32 项详细记录、76 项位置图记录。393 处引用与各自原文精确匹配，机械核验八份均通过；201 项离线测试及编译检查通过。这些数量不代表独立文章数、语义准确率或读者判断。

## 隔离与操作偏差

各任务声明只读说明、单篇 assignment 和单篇 packet；声明的路径与分配一致，均未见其他回答。AGENTS 全程保持原字节，没有为实验临时删去指南。旧项目假设和锚点评价仍自动注入，因此本轮称为单篇隔离、未提供对方输出的双次标注，不能称双盲或独立模型。Root 没有将共享文件系统视作强制隔离，也没有独立重放所有工具轨迹。精确 backend 和独立任务费用未知。

两份 n02 回答首次写入时发现 `responses/` 目录缺失，文件未创建。`a317b4b4f22ef` 自报使用同一载荷恢复；`ad6ae677b7701` 重建载荷时自报三个位置图操作标签发生措辞变化。均未收到校验反馈，但后一份不能算无偏差的首次生成。原始落盘文件不改，操作记录另存；保守敏感性中排除后一份，n02 随之只有一份回答，不能再支持重复一致性。之后先建立输出目录，没有追加这类重试。

## 判定：可恢复的含义与不稳定的字段分开

| 观察 | 原文及回答表现 | 当前判定 |
|---|---|---|
| 多层反馈可保留 | n01 区分玩家本人 64G 卡顿、该玩家所见 UP 主 96G 卡顿，以及配置建议；n04 区分外部作者建议双 HDMI、父亲认为可换线和本人因价格只布一条 | 选中的显式来源链有据支持，不能据此认证反馈或技术结论为真 |
| 未署名实测没有强配作者 | n02 两份均把测试提出者记为 `not_stated`，保留 15 秒视频、约 30–60 秒耗时和超 90% 成功率的报道层 | 当前文字视图内支持；引用 UI 和上游可能另有来源信息 |
| 当前提出者与终极出处混用 | n01“给个参考线”一份记录 proposer 为本文叙述者，另一份为 `not_stated`，但后者 reporting_layer 又明确作者直接给出 | 不是把建议错归给玩家；仍不能把 proposer 当作唯一稳定类别 |
| 暗示预期不能只靠 null 统计 | n01“门槛比你想的高”一份编码为被质疑的低预期，另一份仅在呈现说明保留预期差 | 都没有给实际读者编造具体旧阈值；暗示性 foil 的进入条件尚不稳定 |
| 限制不总被编码为否定对象 | n02“仅支持”在两份回答中都保留适用范围，但 prior_or_foil 为空 | 内容没有丢；事实性排他限制与篇章否定对象之间仍需明确定义，不能按空值推断无否定 |
| 疑问被扩大为行动意向 | n01 一份 `omitted_opportunities[5]` 把 b025 玩家对今年能否玩到稳定版的疑问说成等待意向 | 这处需收窄为时间疑问／不确定。它不在该回答的详细 reader 字段，不能据此宣称详细 reader 字段全错；也不能借 b001 另一条明确等待评论替它补证据 |
| 读者、被引人物和作者分开 | n03 评论者的未兑现刻字经历与作者“今年说不定”等调侃分开；n04 只将所报朋友兴趣作为读者证据，父母另列转述 | 选中焦点支持；没有独立人类观测，也不支持群体比例 |
| 普通条件和有用重构保留 | n03 按是否有喜欢的款式给建议；n04 由外观不满转向珍惜父母痕迹，同时保留审美不满 | 不应把条件比较、价值转向或认知改变自身列为臭味 |

Root 阅读四篇完整原文，按焦点、命题和归属核对八份记录。另一名未见 Root 机会清单或裁定的同家族 Agent 复核 n01／n02；其 103 处原文或回答定位核验通过。独立复核不等于独立模型或人工 gold。

## 不能丢掉焦点选择的分歧

n01 两份详细记录共同选择版本、内存、硬核体验，第四项分别选择未来版本预测与三类玩家建议。n04 共同选择朋友兴趣、布线／投影和家庭价值重估，第四项分别选择洗衣机高度与宜家／定制建议。这些单份覆盖没有被从分母悄悄删除，也没有当作语义失败。

n02 两份都没有为输入文件数量及多数技术性能比较建立详细记录；位置图里出现“导演”不表示已核验所有技术声称。n03 两份都只在位置图和省略说明处理大部分引用卡片，不能宣称每张卡片的第一人称和归属都已详标。n02 根本没有正向读者态度机会，其稳定空列表只能支持不补造的负向检查。

## 与臭味发现直接相关的观察

本轮不增加又一组词频规则，而是保留三个可检验的结构：

1. **反复设定读者需要先完成的准备。** n01 从标题、入坑检查、观看建议、三类玩家到结尾，持续安排“先准备再投入”。其中版本、备份等确有用途；要检验的是反复组织是否仍带来足够的新条件和信息，不是看到“先”就删。
2. **功能说明不断被提升为更大的角色或阶段变化。** n02 从玩具到工业工具、素材到导演、再到重构流程与应对变革，复现可定位。功能列表有信息价值，但并不自动支持每一级更强定位。当前只是候选机制，没有人工强度标签或编辑收益。
3. **结论的粒度超过眼前证据。** n01 的个别高内存卡顿反馈不能单独推出 16G／32G／64G 的通用分档。这里可分析证据对象、条件和结论范围的变化；不能简单认定建议错误，也不能忽略可能在未读引用中的其他依据。

反例同样重要。2016 年 DIY 导览反复强调心意、易上手、教程入口，可能服务于分类和互动；2014 年装修文反复解释具体空间约束，亲情段有明确事件、对话和评价变化。**重复引导、价值重构或否定句自身，都不足以界定读者反感。** 年代和所谓人味也不能替代这项判定。

## 当前决定与下一步

保留 1.1 输出为可审查笔记，停止将通用 proposer、暗示性 foil、整份自由文字的 reader 解释升级为自动特征或训练输入。本轮没有测出 1.1 相对 1.0 的改善，没有 reward、训练导出或编辑效果。

不马上扩成更大的 1.2 schema，也不回改这些已暴露回答使其通过。将明确来源链保留为窄回归例，把歧义、过度解读和未覆盖位置单列。接下来的主要问题是上述结构是否确实对应维护者反感的目标，而非继续追求所有字段形式一致。

已向维护者单独提交 n01 的完整未改原文做主观强度校准，记录在 `reader-calibration-request.json`，当前等待回答。它是新的 discovery 标签，不是作者身份判断，也不验证编辑效果。已有 Microduck／Baidu 标签继续保持，不重复询问。收到新反馈后，再选择足够鲜明的来源及限定的编辑机制；此刻不自动生成下一批改写。
