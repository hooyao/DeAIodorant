## 反馈能够说明什么

读者在方向上偏好这些改写，但各有不同限定。这是真实的阅读偏好反馈，单凭它无法确认改写保留了每个命题，或减少了项目所针对的臭味。Pair 1 的内容疑虑解决前，尤其不能记为通过原意保留的结果。读者也未单独确认 Pair 2 和 Pair 3 的语义等价。

不得报告 100% 成功率、三次经过验证的改写胜出、去臭效果或 SFT / DPO 已就绪。必须区分明确选择、选择幅度与是否满足原意保留约束。

展示的样例包括两篇实用说明和一则公告，可用于检验顺序、条件和文字编辑，但该读者没有在其中发现明显目标臭味。因此，本次预览未能测试改写模型能否改善读者所指的问题文本。在类似挑选出的干净段落上增加模型运行，不能补上这一覆盖缺口。

没有明显臭味，并不等于读者要求每篇都原样保留：同一读者仍表达了一些编辑偏好。这些样例可用于普通编辑或低臭味对照，但不能自动获得“不改写”标签，也不能重新标为臭味阳性样例。

## Pair 1 的原意保留后续检查

人工意见提出后，一名新 agent 仅审阅已展示的文本对，没有接触此前判断、模型标识映射表或事实清单。其主张对齐记录指出两处显式范围差异：

- 原文明示不匹配条件限于核验过程；改写在核验段落内表达该条件时，没有重复这一限定短语。

agent 未认定存在确定的事实删除或无依据添加。上下文可能使两种说法相容，但这不能视为解决了人工疑虑。记录仍为 `human_concern_resolved=false`，不是新的原意保留通过。不得猜测这两处就是读者想指出的具体差异。
