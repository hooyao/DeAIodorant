# 定向真实媒体发现 v1

日期：2026-09-14。状态：一项探索性来源提名，尚非人工确认的强例、改写实验或训练记录。

## 为什么改变选择方法

[撤回 Cowork 任务](cowork-preview-withdrawal.md)，是因为一般可修复性取代了目标覆盖问题。随后的[十二篇文章复筛](target-coverage-rescreen-v1.md) 没有提名持续体现目标的样例。因此没有继续从该样本框准备改写，而是进行一次有界搜索，寻找信息充足且包含被提名风格表现的文章。

使用了一次 Google UI 查询：`site:infoq.cn/article "不是" "而是" "2025" "本质"`。选择可见的国内企业分析结果，并在检查正文前解析出实际 URL。已知标识检查通过。公开抓取使用现有保守客户端，发送一次 robots GET 和一次文章 GET，没有重试，也没有下载媒体。采用已有 0.9 阈值的精确／归一化的／simhash-prefiltered shingle 检查，未在可用受保护数据集或此前两个暂存抽样框中发现匹配。受保护文本和标签未展示，也未提供给评审者。

这是以关键词富集的开发阶段发现，不能估计普遍程度、复现时间发生率或提供独立验证。

## 候选与证据

来源：[百度旧供给／新供给分析](https://www.infoq.cn/article/rDTKqBrlGD5R93NFDOI8)，发表于 2026-05-15；文档 ID 为 `92ade4253c08a43329164bf5`。
正文 SHA-256：`2977deaed4317dd195716a9bd051e69a81d45fc2ffba94db7086aa0418a126e2`。
主 agent 与单独提供任务的评审者都阅读了完整 5,872 字符正文；独立评审者还阅读了全部 64 个 DOM 块。没有生成改写。评审者未读取主 agent 观察或此前评审。

独立判定为 `sustained_target_candidate`，置信度中等，依据是全文反复出现的问题组合：

- 局部技术发布被反复重构为新需求、新供给范式、临界点、新起点和代际架构优势。重复超出单条被引用口号的范围。
- token 计费／开放与 credit 计费／封闭的平台 dichotomy 引出厂商第三条路的主张，却没有证明选项穷尽或成本可比。结尾 Apple 类比提出价格与生态的因果替换，却未展示这一排他比较。
- 所声称的推进有时改变了正在回答的问题：突发算力利用率转到采购／冷却灵活性；门店／工厂协同转到银行采用和汽车训练；marketplace 增长转到基础设施先发优势。

也存在局部措辞缺陷，包括 `主语的变化，背后意味着背后的技术工作` 和 `但确实能帮助我们百度 Create 这次发布会的产业意义`。这些可能的谓语缺口不是唯一提名依据。正文仅有三处字面 `而是`；计数没有单独决定判定。

反证仍相当充分：缓存解释提供了机制，若干对比是有归属的引文或必要技术区分，结论也带有条件。企业活动报道和宣传惯例是合理的竞争解释。七幅被引用图像未检查。文章的生产路径及 LLM 参与程度未知；国内主题和中文署名不能确定这些信息。

## 当前证据边界

提名只是编辑前校准原文目标代表性的理由，不足以证明维护者认为文章具有强烈厌恶性。不得推断人工偏好、严重程度、作者身份或原意保留标签。如果原文目标覆盖被否定，应保留该否定并修订抽样，不能用一般修复替代目标继续推进。
