## 新来源暂存

[限定范围的暂存运行](media-contrast-staging-v1.md) 复用 InfoQ 公开 sitemap 和现有提取工具。在标识 / robots 排除与按固定 seed 排序后，从两个 sitemap 抽样框各固定十二个 URL。XML 不含逐 URL 发布日期；先保留了基于不可用日期提示、选择数为零的初始 manifest，再明确修订为索引抽样框选择。文章发布日期取自页面嵌入状态。

| 阶段 | 数量 |
|---|---:|
| 公开文章请求 | 24 |
| 实际发布日期在 2023 年之前 | 12 |
| 实际日期在 2025-07-01 或之后 | 12 |
| 完整 HTTP 响应 | 24 |
| 非空提取正文 | 20 |
| 本次暂存中确定性的翻译排除 | 4 |
| 剩余可进一步文本检查 | 16：7 前期，9 后期 |
| 语料准入／人工臭味标签／训练导出 | 0 / 0 / 0 |

四次成功 HTTP 抓取的提取正文为空。它们是提取失败，不是完整文章，也不是替补样例。未通过回填失败、时期不符或被排除的项目来改善所观察结果。

标识排除层使用先前文档 ID、URL 和可用 hash。后续机械泄漏审计复用固定的精确／归一化的／simhash-prefiltered shingle 比较，阈值为 0.9。在非空抓取文本中，未发现已知或暂存内部重合。benchmark 正文只在该机械保护检查内使用；标签、模型分数和结果没有导出、交给评审者或用于调优。该保护检查不能保证不存在任何语义重合。

全部来源响应、段落、图像／链接引用、提取限制和时间戳均私有保存。未下载任何媒体资源。当前浏览量是采集时的观察，不是按文章年龄匹配的传播可见度指标。长度与提取成功不等于质量准入。

## 全文评审评审集合

在阅读正文之前，根据元数据选择六篇文章，构成三个临时文本对：企业／云讨论、第一方技术实践、科技新闻报道。这不是匹配且有代表性的语料。云文本对在长度和访谈／观点形式上差异较大；其余配对也保留主题和视觉上下文差异。

评审呈现将原 DOM 文本块用段落间距连接，精确的非空白内容与各自不可变抓取正文相符。没有句子被改写、生成、遗漏或缩减成选取片段。日期／来源元数据对对比评审者隐藏；真实文本时间线索保留，因此盲法不完整。

两名 agent 独立阅读六篇完整文本，在未看到对方结果的情况下提名可能的对比。任务允许弱／无对比和不确定，要求实际证据与反例。

| 文本对 | 评审 A | 评审 B | 解释 |
|---|---|---|---|
| 企业／云讨论 | 弱／无对比 | 不确定 | 销售语言和访谈／观点差异阻碍清晰的目标判断 |
| 第一方技术实践 | 弱／无对比 | 弱／无对比 | 两篇均保留具体机制；仅有精致框架不足以支持判断 |
| 科技新闻报道 | 候选对比，B | 候选对比，B | 可作人工校准的具体全文候选，强度尚未确认 |

一致意见不能把 agent 印象变成人工观察。评审者的模型能力相关，错误也可能相关。未训练分类器、NLP 分数、改写器或偏好模型。

## 来源过程评审与纠正

另一名 agent 检查来源元数据与完整文章上下文。初审错误地把外国来源引文视为整篇编译的确定性证据。执行 agent 按现有项目政策核查该决定；政策允许独立撰写中文报道并综合外国来源材料。

[v1.1 补充记录](media-contrast-qualification-v1.1.md) 保留初审并撤回过度结论。外国引用是已观察事实；新闻文本对属于翻译还是独立中文综合，仍未解决。正式准入继续受来源待核实状态限制。没有要求维护者解决来源来源过程。

这次纠正说明模型辅助分类必须保留支持证据与不确定性。单凭中文署名或外国引文，都不能证明所要求的原创状态。
