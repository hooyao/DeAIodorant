# CR-001：自主编辑预检

日期：2026-09-14。路线：`compact-refiner-v1`。状态：模型辅助开发阶段实验；人工偏好与训练准入仍未测量。

## 问题与解释边界

这条流程能否产生可评审、保留意义的编辑提案？投入 SFT 之前会出现什么失败？本次运行不估计自然臭味普遍程度，不确立读者偏好，不训练模型，也不验证 NLP 奖励。全部语义／编辑评估均属模型辅助，包括独立 agent 的评估。

以下数值来自小型构造开发阶段样本，不能确定某参数规模所有模型的一般能力。助手提案及其评审使用相关的底层模型能力；独立 agent 和隐藏标识不能使错误相互独立。

## 输入与执行

二十四个独立构造事实简报覆盖四种体裁，每种六个：技术解释、实用说明、基于证据的分析、职场／公共沟通。全部名称／事件虚构。简报含 158 个事实清单条目及两句精确锁定句。所有组仅用于开发阶段；未打开旧保留集或最终测试。

两个草稿生成器为 `deepseek/deepseek-v4.1-flash` 与 `qwen/qwen3.8-27b`，在体裁内交替分配。生成使用冻结普通任务 prompt，temperature 0.4，最多 2048 输出 tokens，请求 seed 20260914，禁用 reasoning。未要求坏文字，也未反复生成有效输出直到出现预期标记。

一次原文请求 `cr001-23` 在 HTTP 429 后仍不可用，包含等待超过 120 秒后有记录的一次恢复尝试。没有为它编造文本或语义标签。来源 24 使用原分配模型及请求成功。结果为计划 24 组中产生 23 份实际草稿；全部组留在核算分母。

原文检查与 API 调用流失促成单独冻结编辑阶段 manifest，时间在小模型输出之前。这是原文生成结果后明确的操作修订，不能声称验证性预注册从未改变。初始来源 manifest 和失败尝试继续保留。

## 编辑前的仅针对原文的评审

一名独立 agent 在看到改写前，将原始草稿与完整事实材料包比较；评审输入省略生成器标识。第二名 agent 在未见第一名标签的情况下，评阅按固定 hash 选出的六例。原文忠实度分类六例全部一致。

| 来源判定 | 数量 | 明确编辑机会 | 有限机会 | 无明确机会 |
|---|---:|---:|---:|---:|
| 模型辅助通过 | 13 | 4 | 3 | 6 |
| 模型辅助失败 | 7 | 6 | 1 | 0 |
| 不确定 | 3 | 2 | 1 | 0 |
| API 不可用 | 1 | 未评估 | 未评估 | 未评估 |

原文缺陷包括遗漏要求、增加程序性义务、强化频率／可能性主张，以及把等待联系的操作状态推进为已主动联系。这些是原文生成缺陷，不是小模型编辑器引入的失败。

十二份被模型诊断有明确编辑机会的原始草稿中，八份原文失败或不确定。这是重要选择问题：通过修复内容来改善这些草稿，不能证明保留风格的编辑。同时，十三份可准入草稿中六份没有明确编辑需求。短小且充分指定的任务可能难以覆盖真实编辑需求，但结果不能成为制造更差输入的理由。

## 输入匹配的候选比较

对十三份原文通过草稿：

- U 精确保留原文；
- P 使用 `mistralai/ministral-3b-2512` 与冻结编辑 prompt，temperature 0，最多 2048 输出 tokens，seed 20260914；
- T 是新 agent 的一次提案；它未阅读简报、事实清单、原文评估、P 输出或历史样例，只得到与 P 相同、完整渲染的编辑器输入。

十三项 P / T 输入 prompt hash 全部一致。T 是模型辅助编辑提案，不是人工编辑上界有界。其内部推敲过程、latency 和成本不可用，因此不能与单次托管服务请求构成受控计算预算比较。

候选评审者得到原文、候选文本、合法上下文和锁定内容，作者 / 模型标识隐藏。六个构造语义对照混入其中，但排除于研究计数。六个对照均按预期分类。第二名 agent 评阅按固定 hash 选择的六个实际候选，覆盖五份不同原始草稿。

| 条件 | 实际候选 | 主评审原意保留检查通过 | 主评审失败 | 完全未变 |
|---|---:|---:|---:|---:|
| P：未调优 Ministral 3B prompt | 13 | 2 | 11 | 0 |
| T：新 agent 提案 | 13 | 13 | 0 | 3 |

次级候选评审在六项忠实度分类中与主评审五项一致。余下一项为主评审失败、次评审不确定，二者都未接受该编辑。模型诊断的两项明确 T 改善都通过次评审。这项有限交叉检查不能认证其余候选，也不能替代人工判断。

主评审的编辑诊断与原意保留分开：

| 条件 | 明确 | 有限 | 无 | 退步 |
|---|---:|---:|---:|---:|
| P | 0 | 1 | 5 | 7 |
| T | 2 | 8 | 3 | 0 |

一个 P 候选通过原意保留，却被判风格变差，说明忠实度和实用性不能合成单个自动标签。以上编辑诊断都不是测得的读者胜出。

## 具体失败与有用提案

3B 候选包含以下经模型评阅的失败：

- 将已知两张图片改成 `X` 占位符，并增加截止时间和新指令；
- 反转现有链接继续可用的条件；
- 把连续一次关闭时段改为每日重复时段；
- 将没有同意转成明确拒绝；
- 丢掉与权限无关的访问保证或服务限制。

两个候选还违反精确锁定句。其中一个的费用措辞丢掉“additional”限定；语义解释有歧义，因此确定的精确锁定句违规与可能范围扩大不能混为一谈。增加编辑评论等输出格式违规与事实主张变化分别记录。

三项主评审 P 失败未触发现有数字／受保护字面内容警告检查（`cr001-01`、`cr001-03`、`cr001-14`）。一个通过原意保留检查的 P 候选反而触发字面警告。这说明检查不完整、需要上下文评审，不能将其解释为已验证语义 detector 的 precision / recall 估计。

两名模型评审者都认为两项 T 提案明确处理了独立观察到的局部问题：

- `cr001-08`：把编号不匹配处理和搬运要求移到悬挂步骤之前，保留数量、角色与完成条件；
- `cr001-12`：把涉及“quiet eyes and ears”的不自然邀请改为具体观察／倾听指令，保留活动隐私和测量限制。

大部分其他变化是收紧措辞或格式调整。三个 T 样例精确返回原文。这些是可供人工讨论的有用提案，不是路线已学会去除一般臭味的证明。

## 额外容量对照：CR-001B

初始结果可能反映学生模型选择不佳，不能直接认定普遍需要 SFT。因此单独探索性后续实验将 `qwen/qwen3.5-9b` 应用于完全相同的十三份编辑器输入。它是具备中文能力的容量对照，不是选定的最终学生模型，也不替代 P。

其 manifest 在初始预检观察后、调用之前冻结。十三次请求都一次成功，无缓存复用或重试，经 Darkbloom 返回 Qwen3.5-9B。新增报告成本 USD 0.00100229。Qwen 候选由新隐藏身份的 agent 结合相同语义对照评估。解释时须同时允许架构、语言训练、提供方、评审 agent 以及参数量差异。

新评审 agent 对全部六个对照分类符合预期。十三个实际 Qwen 候选的原意保留判定：八通过、二失败、三不确定。编辑诊断：零明确、四有限、六无、三退步。两项失败分别把无种子也可参加的许可缩窄为关于持有种子的条件，以及漏掉两项不同研究局限。不确定项涉及施事者 / 范围限定成分和新增自动化主张。这些判断仍为模型辅助。

结果削弱了“小型 API 模型都不能遵守契约”的笼统结论：该对照在已评审项目上与 3B 基线有实质差异。但不能据此确定 9B 是合适学生模型，也不能确定更大规模导致差异。模型家族与评审 agent 均构成混杂。尚未测量微调收益；本次所有 API 模型都是未调优基线。

## 成本与操作发现

包含冒烟测试检查、来源生成、P 和 CR-001B：52 次成功 API 尝试报告 USD 0.01012750。十次 HTTP 429 的计费未知；包含预留金额的保守核算总额为 USD 0.05459170，低于 USD 5 工作上限。agent 推敲过程不计入，也不能表述为免费 API 使用。

客户端保留价格上限、精确请求标识、响应元数据、费用预留、失败记录和成功缓存。进程 / 产物检查独立于监控器确定进度与终止。没有重合缓存写入者、模型下载、本地 SFT 或云 GPU 任务。

初版客户端未遵循／保留 Retry-After 头。本次运行保留该操作局限。后期阶段使用零自动重试；全部推理完成后，单独版本化客户端维护修复按服务器指示退避。精确维护前代码和输入已归档，纠正不会追溯改变实验。

[维护记录](../client-maintenance-2026-09-14.md) 说明修复。最终实现通过 113 项离线测试和规定编译检查。记录 / hash 验证、Markdown 链接、JSON 解析、忽略规则和凭据排除也通过。这些检查不能验证读者收益。

## 决策

不能仅凭这些结果启动 SFT 或请求 GPU。优先解决三个具体问题：选择具备中文能力的学生模型基线；确定人类是否偏好少数有明确收益的安全提案；以及通过可靠语义评审收集已接受编辑 / 不编辑文本对。3B 失败不能说明全部小型模型失败，T 通过结果也不能说明小型学生模型能从几百例学会这些操作。将范围、条件和未变行为明确保留为训练数据关注点，不能奖励表面标记删除。

保留看似可接受及失败提案、未改样例、原文隔离和 API 调用流失。缺少数据契约要求的人工证据时，没有 SFT 或 DPO 记录具备资格。已从两项明确 T 提案和一项较小编辑准备三对定性读者预览。这是评审后的讨论选择，不是留出评估基准或模型排名。
