# 现有媒体开发阶段材料清单

日期：2026-09-14。实验方案与产物 schema：`deaiodorant-media-development-inventory-1.0`。

本清单将小模型改写路线重新连接到实际目标：例如现有 InfoQ 导出的完整中文媒体文章。保留此前语料、读者观察、失败干预和来源过程警示。这是开发阶段准备，不是新验证结果或干净语料准入决定。

维护者同日后续校准明确：不能将候选列表解读为已确认严重阳性；先前标注样例对于目标问题太弱。所列正文和旧意见保持完整，仍可用于来源过程及开发阶段历史。参见[校准目标](../../../target-feature-discovery.md)。

## 范围与复现

离线脚本仅读取 `data/pilot/monthly/`、`data/annotations/` 的九个持久化文件和两份指定历史证据报告。测量存储正文并计算 hash，不展示、复制、编辑或向模型提交正文。未使用网络请求、模型调用、训练、翻译测试、最终测试文本或封存保留集。存储的按月正文被视为全部可用文章导出；字节 / 计数检查不能确定它相对在线来源页面的完整性。

```powershell
python experiments/inventory_media_development.py `
  --output-dir data/local/compact_refiner/media-inventory-v1
```

输出是被忽略的本地研究产物：

- `documents.jsonl`：每个现有按月正文一条记录，包括原元数据、文件 / 归一化文本 SHA-256、计数、一致性检查、准备角色、来源过程状态和读者记录精确引用；
- `reader-observations.jsonl`：全部 73 条持久化观察，逐字保留，附原文件标识和 JSON 指针；
- `annotation-summaries.json`：全部九份来源汇总与轮次意见，与逐文档反馈分开保留；
- `source-hashes.json`：全部 54 个盘点来源文件的 hash；
- `summary.json`：精确计数、边界、复现命令与局限。

脚本拒绝已有输出目录，且要求输出在 `data/local/` 下。复现应使用新的版本化目录。写输出前再次检查来源字节，若发生变化则报错。文件 hash 保留磁盘标识；内容 hash 按试验导出器惯例归一行尾并移除其附加的一个末尾换行。此过程不重写正文或历史元数据。

## 较低臭味与对照观察继续分开

- `b77b09a419c1631227112f0c`，后期 InfoQ，局部证据混合。读者认为第 19–22 行大部分可接受，同时指出具体框架化表达；针对第 7–10 行 v2 pair 的原评语为“这两个几乎没有差别，而且AI臭味也不严重”。这支持较低臭味段落观察，不是干净全文。
- `bf1abf6ca461ec0bbac14bd7`，前期 InfoQ，第 28–32 行，被评为通顺，评语为“这段我看不大出是ai写的，没什么臭味”。这是已暴露的前期对照观察，不是作者身份或时期等价证据。
- `213dcab213f816c7c548fc09`，第 270–275 行，获得“这像是早期AI的文本，臭味不强，可以读一读”。其 `original_link_marker` 阻止将其当作已准入原创对照。
- `a127f5baf364930a89fb4005` 的 v2 评论为“没有任何区别”。平局不能区分两者都可接受还是都有问题，不是低臭味标签。
- `9e271d7b118c949e83c9ff8d`，前期 InfoQ，第 10–12 行，难读：“信息很少，而且信息重要程度很低，但是句式繁杂，上下文乱切，逻辑跳跃”。早期材料也可能有相关阅读阻力；不能把发布时期作为目标标签。

## 路线改变后仍须保留来源过程冲突

试验元数据对全部 30 篇都记录 `is_translation=false`，同时对三篇记录 `original_link_marker`：`73e9f6e61e27e1e32264551f`、`aa8f2104314751c5873dbab7` 和 `213dcab213f816c7c548fc09`。这些标记未解决；原文链接本身不足以判断与来源的关系。

更严重的是，`experiments/pilot-direction-probe.md:21–22` 已把 `b186cdd4f9004e0413395bf3` 识别为已知后期译文。薄弱试验元数据没有承接该发现。后来 v2 读者工作包含其一段，并记录“B很绕口”及改写偏好。应保留历史观察，同时将文章从主要路线准入中排除。不得静默修改冻结记录，也不得以偏好作为对称翻译排除的例外。

因此清单记录一篇已知翻译排除、三篇未解决来源过程标记，以及 26 篇没有已记录排除但来源过程未解决的文档。记录中 **来源过程通过为零**。公开可用不能确定训练权利：全部 30 篇的 `training_rights` 仍为 `unverified`。

## 对下一项实验的直接影响

使用两篇优先真实文章及其完整存储上下文。生成编辑前，先建立文章级问题图谱和原意保留台账。解释新全文候选时保留逐段历史。候选应与同一未改文章比较，并审计跨段过渡和风格损失；不能把框架化表达词变少等同于成功。模型 / agent 评审仍属开发阶段证据，新的人工全文偏好仍未获得。这一准备阶段不需要 SFT 或 GPU。
