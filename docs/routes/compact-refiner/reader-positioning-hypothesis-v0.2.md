# 信息文章的讲解姿态：假设 0.2

日期：2026-09-15。依据是维护者新反馈与此前两篇强样例的原文。本文补充[0.1 版假设](rhetorical-mechanism-hypothesis.md)，不回改旧标注。

维护者确认《亡灵遗产》“不胜枚举，很臭”，并明确指出：先说看得见的部分／看不见的部分更大、入坑前先看几个坑、内存门槛比你想的高。四处原文与人工措辞已分别保存，没有新增作者身份或数字评分。

这次反馈要求收紧此前的解释：**不必先证明内容无用、逻辑错误或证据不足，才能处理令人反感的表达。** 可见界面与机制改动确有区别，运行内存也有实际信息；叙述中反复安排读者先理解什么、再揭示更大一层、或假设读者原先低估，仍可让读者不舒服。

当前关注三种相连的呈现方式：

| 观察 | 所做的篇章动作 | 要保留的内容 |
|---|---|---|
| “先说看得见的部分”后接“看不见的部分更大” | 先安排一层阅读，再提高下一层的重要性；属于 metadiscourse 与 scalar framing 的交叠 | 界面、物品管理与游戏机制的具体改动，以及原文“改动更大”的比较 |
| “入坑之前，先把这几个坑看一遍” | 将正文安排写成对读者的阅读指令 | 入坑前的注意事项及实际操作先后 |
| “门槛比你想的高” | 为读者设定一个未观察到的较低预期，再作提醒 | 本段已有的内存需求判断、配置数字、来源与条件 |

这些是可审查的行为解释，尚未证明是感受的唯一原因。不会把它们变成“先”“更大”“门槛”的禁用词表，也不将有用的设问、必要提醒或实际安装顺序一并删除。后续应比较直接介绍对象／条件的写法是否更舒服，并检查信息是否保住。

项目目标是让公众信息文章的读者看得舒服、把问题看明白。句法、篇章和措辞分析为这个改写目标服务。艺术文体、文学性或作者身份判断不在产品范围内；旧个人叙事样例只保留为语言学或工程反例，不据此扩张产品。

当前有两篇由同一维护者明确评价的强样例，均来自 SMZDM，不能据此推断普遍率、训练成因或任一关键词的因果效果。下一项具体工作是[有限改写试做](information-refinement-pilot-v1.md)，没有 SFT 或 reward 升级。
