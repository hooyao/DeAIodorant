# 候选生成机制：参考解释与证据的区别

版本：`generation-mechanism-hypotheses-0.2`。日期：2026-09-14。
Provenance：维护者提供的 Gemini 讨论，明确仅供参考，收到时对比上下文审计已经运行。它是没有支持性引文或受控训练证据的外部模型解释。当时进行中的两次独立复核没有收到它。

## 有用的语言学假设

| 假设 | 可观察预测 | 当前检验边界 |
|---|---|---|
| 反复宣称更深解释，替代实际说明 | 多个局部对比否定浅层标签、提出更宽泛的评价标签，却几乎没有增加不同的支持 | 在整篇文章中描述两侧命题、重复动作和提供的证据；不推断训练激励 |
| 反复框架伴随论元或指代不连续 | 对比改变谓词的语义主语，或在上下文中留下未解决关系 | 区分显式主语省略、可恢复指代、语义角色不匹配和真正未解决的指代 |
| 跨语言改编保留公式化框架 | 对齐原文与中文片段共享重复对比位置，或出现关系不匹配 | 需要真实对齐原文；仅凭外文引用或翻译腔印象不能确立改编 |
| 压缩削弱说明 | 实质主张都在，但关系或指代未充分交代 | 确认修复是否有现有信息支持；不能编造缺失前提 |

这些是语言行为的候选解释。标记频率、语义贡献、感知反感和阅读困难分别测量。当前审计不因这份参考新增标签或阈值。

## 缺乏支持的因果主张与技术纠正

- DPO 通常直接优化偏好对，不要求另行拟合 reward model。preference optimization 可能集中强化风格习惯，但参考材料没有证明该构式获得奖励，也没有证明 reward hacking 导致其观察频率。
- 合成数据可以传递教师模型的风格规律。指数放大、普遍退化、从私有推理转移到公开中文输出，都是需要额外证据的主张，不能仅由使用合成数据推出。
- 训练接触以英语为主，不证明内部存在字面意义上的英语优先推理与逐词中文解码流水线。这需要具体模型证据。
- 表层论元缺失或别扭，不能确定原因是注意力衰减、greedy decoding 或 length penalty。参考例句 `这不仅不是技术的退步，而是在实际业务中落地了降本增效` 需要分析 `这` 的所指和平行结构；没有重复主语，本身不能证明分句不合语法。
- 比较表声称早期 GPT-4 训练数据纯人类、无污染、对齐一律温和且中文语法完整性可靠优越，所给材料并不支持。不据此推断非公开训练数据构成或模型内部机制。

## 日后可能区分机制的实验

1. 固定语义任务说明并控制输出长度，比较中性说明 prompt 与明确要求反直觉或深入分析的 prompt。框架增加只能显示 prompt 敏感性，不能确定训练原因。合成输出是工程材料，不是目标媒体证据。
2. 依据有记录的来源 provenance，比较对齐的原创与翻译媒体段落。译文不纳入仅含原创的主要 cohort。
3. 若可获得可比的 base 与 post-trained checkpoint、偏好数据和合适算力，可在各阶段评估同一任务。仅模型或版本差异不能单独识别 RLHF、DPO、SFT 或数据混合的作用。
4. 受控重复蒸馏研究需要固定教师与学生配置，并有非递归对照，才能评估风格继承或放大。当前改写目标不要求此研究，也未安排执行。

## 当前决策

依据原文的上下文和阅读缺陷审计照原计划继续。参考材料用于组织竞争性解释，不用于给文章贴标签，也不用于因果解释现有样本 8.3 倍计数比。无需先破解非公开训练机制，就能检验读者收益与意义保留。参考材料本身不授权新的生成实验、训练、模型下载或 GPU 请求。

## 后续参考：英文写作与翻译链

维护者又提供了一份没有引文的 Gemini 解释，讨论英文读者抱怨、阅读努力与信息回报失衡、公式化词汇、均一节奏及负担转嫁。维护者还明确提醒：LLM 将英文译成中文之前，LLM 生成的英文本身可能已经很差。这份参考在两次独立语义复核实质完成后收到，不改变其标签。

有用假设涉及重复命题、冗余 metadiscourse、夸大结论，以及读者重建或核实论证所需的工作。即使单句合乎语法，这些问题也可能成立。诊断设计在真实材料可用时保留原文与译文配对，不推断任一作者身份或翻译方式。

参考中的更强主张仍未经核实：英文句法普遍无懈可击、整个社群反感的 prevalence 或强度、低 perplexity 与差写作直接相关，以及已经证明的神经或 mentalizing 机制。信息价值取决于语义和任务，token entropy 不能替代。熟悉术语、对称句法、三项列举或 `robust` 等词，都可能符合上下文。

[校准后的目标](../../target-feature-discovery.md)现在明确区分仅含原创的时间对照与产品更广泛的翻译媒体诊断范围。不预设原语言文本质量高；声称翻译恶化某个具体缺陷，需要配对证据。

维护者随后明确纠正，取代本记录此前对排除翻译的任何强调：中文译文是核心改写目标，所有 provenance 分层均保留在研究中，仅含原创的筛选是一项 sensitivity 或对照。维护者授权沿当前依据原文的阅读缺陷与有限修复路线决定方向。不增加关于 RLHF、DPO、合成训练或英语优先内部推理的推断。
