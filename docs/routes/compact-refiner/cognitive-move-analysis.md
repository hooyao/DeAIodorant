# 关联原文证据的解释与纠正篇章动作分析

Protocol：`cognitive-move-analysis-1.0`。日期：2026-09-14。
状态：探索性的标注示例，不是自动检测器，也不是已验证的 reward。此前对机制的解释是待检验的假设。

## 单位与范围

篇章动作（discourse move）是完成一个连贯交际操作、且能关联到原文的最小片段，同时附带理解它所需的上下文。它可以占据句子的一部分、多个句子、标题及其展开，也可以依赖跨段落的支持。不要强行把每个句子都套进 A 与 B 对立的模板。分析者描述的是文本中的动作，不是读者实际的心理状态，也不是已观察到的模型内部过程。

将检测、语义描述和评价分开。必要的纠正也可能呈现读者指出的表面风格；风格令人反感的标题也可能提供有用的结构。局部没有明确提出误解，本身并不能证明存在 straw man。未经核实的主张不自动等于错误，有用的回顾也不一定需要增加新事实。

## 结构化动作记录

每条记录包含 ID、文档及文本视图标识、精确原文片段、上下文 block ID，以及以下语义字段：

1. `operation`：纠正、范围收窄、解释、推断、评价性重构、回顾或议程设置。确定主要作用后，允许记录多个作用。
2. `question_under_discussion`：中性描述该段落回答什么问题，并以 `explicit`、`analyst_reconstruction` 或 `unknown` 标明来源。不要把分析者的重构当作原文引述。
3. `prior_or_foil`：原文若给出了被否定或先前的主张，则记录该主张、所在位置，以及它是在此处引入、此前已出现、引述自他处还是来源未明。明确区分“命题被否定”和“有证据表明读者确实相信该命题”。此字段可以为空。
4. `asserted_or_promised_content`：肯定主张、限定、价值重点或组织内容的承诺。保留实体、时间、范围、情态、归属和数量。议程承诺不是事实纠正。
5. `relation`：命题之间表达或暗含的关系，包括同一维度上的备选项、限定或子集、可兼容的不同维度、因果、手段与目的、重述、认识层面的加强，或未确定。关系类型的观察不是形式化 entailment 证明。
6. `grounds_and_warrant`：精确的证据片段、原文实际提供的推理连接、合理但未明说的连接，以及仍然未知的部分。区分文章内部的支持与经过独立核实的事实。
7. `information_update`：具体化、澄清、限定、重新组织、回顾、价值优先级、缺乏支持的外推，或贡献不明。重复的信息仍可能帮助读者定位。
8. `stance_and_presentation`：可观察到的确定性、纠正、权威、直接对读者说话、排比或 metadiscourse 表现，不揣测动机。描述其他位置的复现时，给出精确原文定位。

最后分别评估：内容及关系状态、可能的风格负担、保留的用途、其他合理解释、置信度和未解决问题。不提供整体臭味分数，也不添加逐单元的人工严重程度标签。

## 固定分析示例

使用六个已经暴露的单元，选取目的是解释上的对照，而非估计 prevalence。标注任何单元之前，先读完两篇完整原文：

- SMZDM 标题：读者明确定位的议程框架；A 可以不存在。
- SMZDM b006 平台区分：读者指出的单独使用 `是` 的形式，同时保留其有用的具体区别。
- SMZDM b011 产品价值重构：保留 `核心` 和学习用途这一条件；不要把重点强调变成原文并未声称的逻辑矛盾。
- SMZDM b015-b017 成本推断：将 b013 和 b026 作为上下文检查，包括部件与规模差异、已有零件以及估算的限定。
- Baidu b012 缓存机制：不要求存在被否定说法的普通解释。
- Baidu b058 Apple 因果替换：将 b057-b064 作为上下文检查；区分原文主张、类比与已确立的因果关系。

原文及 block 位于 `data/local/reader-style-anchors-v1/smzdm/` 和 `data/local/targeted-media-discovery-v1/baidu-supply/documents/92ade4253c08a43329164bf5/`。
SMZDM 分析文本的 offset 不包含发布者的引用标记；标题 offset 指向 metadata.title。Baidu 的 offset 指向已保存的正文。所有引述片段都必须通过精确匹配验证。语义改述明确属于分析者生成的字段，绝不能替代原始文章或原文引述。

## 可靠性检查与后续计算

检查不同措辞能否保留同一动作表示，以及主张、极性或范围改变时，表示是否随之改变。这些是后续验证要求；仅仅写出等价的分析记录，并不能证明自动模型具有 invariance。任何人工构造的文章都不能因此成为新的强正例。

传统 NLP 可以辅助句子及 block 导航、否定、情态和实体提取、coreference 候选识别、篇章标记搜索，以及重复位置定位。它不能可靠判断 A 和 B 是否针对同一维度、warrant 是否充分，或读者是否需要某次回顾。依据原文的 LLM 标注和独立复核可以帮助建立初始记录；这些仍是可能出错的测量，需要保留证据并跟踪分歧。不得悄悄把历史词汇及 UD 支持探针升级为通用语义支持判断，也不得把它重新包装成已验证的质量分数。

先在有限集合上证明标注可用且可重复。之后再检验所提出的问题类型，是否能预测同一文章中兼顾意义保留和读者偏好的有用修改。再往后，才评估选定成分能否以低成本测量，或蒸馏后用于改写及 reward。这六个分析示例不构成新的批量标注任务、文章改写、SFT、GPU 任务或标量 reward。
