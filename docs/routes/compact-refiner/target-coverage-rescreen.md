# Cowork 样本被否定后的目标覆盖重新筛查

Protocol：`target-coverage-rescreen-1.0`。日期：2026-09-14。
目的：在再次改写或请求读者反馈前，纠正样本选择。这是探索性提名，不是臭味分类器或效果研究。

## 要纠正的选样失败

维护者此前已经认为 Cowork 的 AI 臭味较弱。助手仍因正文可用、存在语法缺陷、可以准备经过意义保留复核的修复，而重复投入工作并请求读者反馈。这用一般可修复性替代了对目标现象的覆盖。将翻译纳入产品范围不能为这种替代提供依据。

维护者进一步解释，Cowork 可能通过翻译继承英文 LLM 的问题，同时仍不足以体现鲜明的中文 AI 写作特征。翻译 provenance 是解释背景，不是二元严重程度标签。不得据此认定所有译文都缺少目标现象、所有直接中文写作都有该现象，也不能凭中文姓名、主题或没有翻译 metadata 就证明是中文原创。

Cowork 读者预览 v1 因样本不匹配已撤回。保留其输入、修订、语义复核、渲染工作和维护者原始反馈。这次否定没有提供 A/B 偏好、未改善结果或意义保留判断。不要以可读性标签重新提交同一任务。

## 有限范围的重新筛查

通读已采集的 `data/local/media-provenance-extension-v1/` 中全部十二篇后期完整正文。选择这一抽样范围的依据是时间较近且材料可用，其中既有目标标记次数为零的文章，也有非零文章；不得按次数排序或筛选。这些是已经暴露的 development 文档，不是新的 validation。本次重新筛查不生成新正文、改写版本或用户任务。

逐篇记录：

- 格式，以及是否符合完整信息型媒体文章；
- 来源、翻译和引用证据，以及未知项；
- 是否持续聚集了目标问题，并给出精确原文证据和段落位置：反复出现的不必要对立、重复抽象结论、论元或指代不连续，以及推进关系未连接；
- 必要对比、连贯说明、引述或体裁解释，以及其他反例；
- 是否只有一般翻译腔、孤立错字、提取 artifacts、术语、推广语气或缺乏支持的事实；
- 提名结果：`sustained_target_candidate`、`weak_or_ambiguous` 或 `poor_format_fit`，附不确定性和具体理由。

不要求必须提名候选。事实缺乏支持或单个语病句，都不能单独将文章变成风格强烈的正例。长访谈中标记次数高也不够。反复出现的操作需要在全文中有可辨认的对应实例，普通访谈回顾或技术区分仍可能合理。

这些结果描述助手的筛查，不代表维护者感受到的严重程度、作者身份、来源或训练标签。若找不到足够鲜明的对照，就保留这个失败，不为凑读者任务数量而填补样本。不要仅因筛查结束，就将新候选发送给维护者。
