# 文档语言规范与迁移记录

规范版本：`documentation-language-1.0`。生效日期：2026-09-14。

维护者明确要求：项目文档统一使用中文，仅在需要时保留英文专业术语。本规范覆盖此前要求文档、说明和研究解释使用英文的约定。

## 适用范围

README、Agent 指南、贡献指南、设计文档、研究协议、实验记录、研究报告、报告模板、PR 模板，以及工具生成的使用说明，均使用清楚、自然的中文。标题、表头、图注、解释和结论也遵循此规则。

专业概念可以保留稳定的 English terminology，例如 NLP、SFT、DPO、RLHF、Universal Dependencies。首次出现且有理解成本时，补充中文解释。普通叙述不能因为夹杂术语就整句保留英文。

代码标识符、命令、参数、路径、URL、模型名称、schema 字段与状态值等保持原样。原始语料、原文引述、已有人工标签、冻结的 benchmark 输入和实际执行过的 prompt，保留其原始语言和字节。本次文档迁移不重新执行研究，也不改变历史证据的含义。

## 英文原版与复现

本次迁移标识为 `documentation-zh-migration-v1`。修改前已将包含未提交研究成果在内的文档逐份保存到 Git 忽略的目录：

```text
data/local/documentation-zh-migration-v1/
  originals/
  manifest-before.json
  manifest-before-extended.json
```

两个 manifest 记录修改前的路径、字节数与 SHA256。扩展版本还包含 PR 模板与本地使用说明生成器的源码原件。此前研究产物记录的 protocol hash 指向当时的英文版本；核对这些旧 hash 时，应读取 `originals/` 中的对应文件。不能用译文替换原件后，反过来重写历史产物中的 hash。

语言迁移不改变研究 protocol 的科学版本。历史计划、已撤回方案、失败实验和证据限制都继续保留；它们不会因翻译变成现行方案。新增或修订研究内容时，仍须另行记录决策与 protocol 版本。

## 迁移方式与检查边界

入口指南和当前研究方法由 Agent 逐份翻译。迁移初期曾使用 OpenRouter 上的 Astra 辅助批量翻译；当前 Agent 本身即为 Astra，这一调用方式没有必要。接口返回 HTTP 402 后已停止所有外部翻译调用，剩余迁移由当前 Agent 和 subagent 离线完成。维护者随后明确要求：OpenRouter 仅用于快速、便宜的小模型；需要强模型时，由当前 Agent 直接处理或使用当前环境的 Astra subagent。

此前调用的请求身份、模型、prompt 版本、用量与费用记录保留在私有迁移目录。成功返回请求的已知费用合计约 $2.69；停止时仍有两笔请求未返回，不能据此确定最终账单。失败或中断请求的保守预算预留不是已确认收费。密钥仅从被 Git 忽略的 `.env` 读取。

批量翻译先保护代码块、inline code、链接目标、URL、数字和已有中文片段，再恢复原值；检查标题结构、遗漏和残留英文叙述，并抽查研究含义。机械保留检查只能验证指定内容与结构是否保持，不能证明整份译文的语义完全等价。

私有迁移目录保存脚本、配置和检查结果。已有成功响应可以复用；接口或校验失败时保留原文件，修复后再处理。复用缓存的操作与具体文件清单以该目录的 manifest 和结果记录为准。

原 API 迁移脚本的执行入口已禁用。保留它仅用于解释历史配置和恢复已返回缓存，不能重新启动外部 Astra 调用。

## 完成结果

81 份既有仓库 Markdown 文档已迁移为中文，另新增本文。报告模板、PR 模板及生成本地登录说明的文字也已同步。

保留检查覆盖全部既有文档：64 个可执行或结构化代码块、1,611 个原有 inline literal、150 处 SHA256，以及原有链接、标题层级和表格结构，均未发现缺失。说明性流程图已翻译；真实实验 prompt、问卷原句、brief 的原始字段值及公式保留原文，按需补充中文说明。

复核修正了几处误译，并通过数值对照补回一段漏译的历史结果。原始数据与冻结实验输入未改动。默认离线测试为 **168 passed**，所要求的 compileall 检查通过。

逐文件修改前后 hash 和检查结果保存在 `data/local/documentation-zh-migration-v1/manifest-after.json`。下列命令仅运行本地保留检查，不调用模型：

```powershell
python data/local/documentation-zh-migration-v1/finalize.py
```

## 后续换机交接

维护者随后明确要求将本地产物与 corpus 一起推送，凭据除外。本次选定的 `data/local/` 与 `feature_runs/` 历史文件因此显式入库，包含上述原件和迁移记录；文中“私有／被忽略”描述的是产生时的状态和新运行的默认规则。当前可恢复文件及操作入口见 [HANDOVER.md](../HANDOVER.md)。API 密钥仍不入库，历史 API 迁移入口继续禁用。

交接又更新了入口文档和阶段说明；`manifest-after.json` 是当时中文迁移完成的快照，不随以后编辑回写。新机器用 handover 核验入口和产物 manifest 检查当前文件，不将旧语言迁移检查器当作持续不变的研究 protocol。
