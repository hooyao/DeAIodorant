从 2021 年蔓延至今的元宇宙热潮还余温尚在，2022 年，Web 3.0 作为横空出世的“新宠”，又掀起了新一轮狂欢。

元宇宙和 Web 3.0 又是什么关系？有专家认为，Web 3.0 是一个代表下一代互联网的概念，元宇宙是一个应用的形态，所以元宇宙应该是 Web 3.0 时代的一类应用。

然而，在很多人对 Web 3.0 这个突然火起来的概念还未完全理解时，已经有一批人预言着它的未来：有人认为，Web 3.0 将是互联网的未来式，它将代表着对互联网的根本性改造；也有人质疑到，Web 3.0 只不过又是一个帮有钱人收割韭菜的诈骗游戏，究竟谁对谁错，还得经过时间和实践的双重验证。

那么问题来了：

  • 业内对 Web 3.0 是如何定义的？是否能有一个较为统一的概念？

  • 在构建 Web 3.0 应用过程中，会用到哪些相关技术？

  • Web 3.0 如何助力现有的业务发展？目前有哪些较为成功的实践案例？

  • Web 3.0 未来发展将面临哪些困难和挑战？又有哪些机遇或突破点？

为了解决这些疑惑，给大家提供一些借鉴和思考，将于 7 月 31 日 -8 月 1 日举办的 QCon 全球软件开发大会（广州站）上，我们设置了「Web 3.0 基础设施」专题，邀请到腾讯云区块链资深架构师梁永甫担任出品人。我们计划从硬件、区块链和上层应用三个角度去挖掘业界对 Web 3.0 的探索与实践，其中将重点关注基于区块链的分布式系统、数据安全、隐私保护、VR 等方向。

除上述专题外，我们围绕“数字化”、“云原生”、“国产化”三个关键词，策划了一系列相关专题：

数据驱动决策

目前国内很多一线大公司都已过了高成长的时代，组织和业务能否快速做出正确的决策也变得越来越重要，比如如何持续地组织成长、快速地产品创新、敏捷地特性迭代、高效地运营营销等，这些都可以基于数据驱动决策来进行赋能。

演进中的架构

基础设施不断更新，架构该如何随之变化，在演进过程中应该做哪些取舍？其中，中小企业上云处于关键进程，多云架构如何选择，如何控制成本? 而对大型企业而言，云原生化走入深水区时，如何进行多云管理，如何在云上持续运营？本专题将关注云上架构演进及其他架构演进中的思考，重点关注反模式。

现代数据架构选型

数据仓库（Data WareHouse）和数据湖（Data Lake）存在已有一段时间，各有千秋，又各有不足，在大多数情况下，二者可以很好地共存和互补。但如今，湖仓一体（Data LakeHouse）的概念横空出世，这是一种全新的架构，它将二者结合，用作数据仓库和数据湖的单一平台。但它是否真的能带来两全其美的效果？本专题将探讨围绕数据仓库、数据湖、湖仓一体所做的技术选型。

核心系统数字化转型

对大多数传统企业而言，核心系统的数字化转型是一个复杂且浩大的工程，本专题希望借助先行者的成功转型经验，帮助该类企业可以高效、低成本、安全地度过转型期，少走冤枉路。

AI 工程与 MLOps

未能投入生产的模型无法为企业或组织创造价值，作为 AI 工程中极其重要的组成，MLOps 的出现正是为了减少这种无用功。其提出了众多解决方案、最佳实践和工具，来帮助算法模型切实落地到业务实践中。

XOps

Ops 相关概念激增。总而言之，这一类词的出现，代表着企业对于强化不同开发团队之间合作互通的需求，以提高工作流程的可扩展性和自动化，帮助企业高效生产。

大前端技术融合

如何通过业务视野和技术视野进一步扩大和丰富互联网领域？新领域技术融合的优秀范例，对互联网自身业务的发展和技术上的探讨都深有意义。本专题将关注大前端前沿技术与最新技术的融合实践。

同时，我们还关注算法应用、移动端质量保障、智能制造技术、运维开发等方向，更多专题及其具体内容正在打磨上线中，敬请关注！点击此处了解更多详情。
