# CR-002: Full-Article Source Probe

Protocol version: `compact-refiner-full-article-source-1.0`.
Status: retained proposal, stopped before execution after the maintainer
confirmed real media articles as the target. No article was generated by this
protocol. The task file remains intact as a possible auxiliary engineering
resource; it is not the next main experiment. See the
[calibrated objective](../../target-feature-discovery.md).

## Question

Do ordinary full-article requests produce development inputs that plausibly
contain the reader's target phenomena? The first preview used constrained short
notices/instructions and did not establish that coverage.

## Generation-chain prerequisite

Verify the original texts through prompt, source request, cache response, stored
draft, and reader-packet hashes. Distinguish an actual source-side rewrite from
upstream prompting that already shapes prose. Preserve the audit and the old
experiment; do not reclassify those original texts after the fact.

## Frozen task boundary

Use the four tasks in `experiments/fixtures/compact-refiner/article-tasks.v1.jsonl`.
Each asks for a complete 1800-2400-character Chinese article for a stated
audience and venue. Each request is one user message, exactly the stored `prompt`.
There is no supplied model article, prewritten factual paragraph, style guide,
anti-cliche instruction, desired smell marker, or request to write badly.

The source task intentionally permits ordinary conceptual exposition. Specific
factual assertions, statistics, sources, or anecdotes generated by the model
are unverified. Preserve and flag them; this source-style probe does not grant
training admission or factual certification.

Run every task on two live verified model IDs, yielding eight planned full
articles and four underlying task groups. Responses to the same task are not
independent samples. Retain all complete responses and operational failures;
do not regenerate valid articles until they look sufficiently formulaic.

Model selection, catalog prices, decoding/reasoning settings, request budget,
input/code hashes, and exact commands must be frozen before the first response.
The default output budget is 6144 tokens, temperature 0.7, seed 20260914 when
supported, and reasoning disabled. Record lack of provider seed/revision
guarantees. Use a USD 1 API cap for this bounded probe, no local GPU or training.

## Integrity and review

Store each full returned article as UTF-8 with an exact content hash. Record
the raw final-content provenance and any parser extraction, but perform no
rewrite, truncation, cleaning, heading removal, or paragraph selection before
source review. Preserve the full title, headings, paragraphs, and ending.

Article length, paragraph count, finish reason, and presence of unsupported
specific assertions are diagnostics. Do not silently treat an undersized answer
as a full-length success or automatically replace it. No style threshold or
authorship classifier decides source admission.

Two independent agents may read anonymized whole articles and identify bounded
evidence of generic expansion, ornamental reframing, unsupported conceptual
links, repetitive organization, or awkward figurative language. They must also
record useful rhetorical structure, clear passages, counterexamples, and
uncertainty. These are model-assisted localization proposals, not reader labels.

Any extracted span must retain offsets and a link to the complete article;
isolated spans cannot replace the primary full-text review. Use a fixed
hash-based rule within prespecified review categories for any small discussion
packet, disclose the selection, and keep all original articles available.

## Decision boundary

If agent review finds no plausible target coverage, record that negative result
and diagnose prompt/model/task scope before expanding. If it finds concrete
candidates, prepare a small original-only full-article review for the maintainer.
Only the maintainer can resolve whether those candidates match their intended
reader experience. Do not start rewriting or infer human smell labels from
agent agreement. Clean or uncertain cases remain controls.

This is a new development probe, not a return to pre/post classification,
an opening of legacy reserves, an SFT dataset, or a reward-validation study.
