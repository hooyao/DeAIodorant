用脚本调用本地 Photoshop 的「矩形选框 + 内容识别填充」，一键清除 AI 图片水印。 完整代码已开源：
https://gitcode.com/leleloveegg/useps
一、背景：为什么要做这件事
现在用AI 工具生成的图片，都会带上平台水印：
左上角：透明文字
右下角：标 + 文字角标
这些水印虽然不大，但对设计师来说，交稿、出图时总想处理干净。市面上的去水印工具要么要钱、要么效果差，而每个设计师电脑上其实都装着一个「去水印神器」——
Photoshop
。
Photoshop 的「内容识别填充」（Edit > Fill > Content-Aware）是去水印的经典方案：选中水印区域，PS 会自动分析周围的像素纹理，把水印"补"成背景。这个功能对缎带、渐变、城市剪影这类复杂背景效果尤其好，比普通 OpenCV 的 inpaint 算法自然得多。
但每次手动操作太麻烦：打开图 → 放大 → 框选 → 填充 → 保存……几十张图能弄到怀疑人生。
所以我把整个流程写成了一个 Python 脚本，自动控制 Photoshop 完成全部操作。
二、这个 Skill 能干什么
useps
（Use Photoshop）是一个通过 COM 接口自动控制本地 Adobe Photoshop 的 Python 脚本，专门用来去水印：
自动完成的全流程
自动定位
：用 OCR 识别图片里的水印文，自动算出水印位置
智能扩展
：识别到右下角文字后，自动把选区向左、向上扩展，覆盖文字左侧的图形图标（OCR 认不出图形，这是最容易漏的地方）
模式转换
：自动把图片从索引色模式转成 RGB（否则 PS 的填充命令会报错）
内容识别填充
：对每个水印区域执行矩形选框 + Content-Aware Fill
保存验证
：另存为新 PNG（不覆盖原图），再用 OCR 复查水印是否清除干净

四、脚本核心原理（给想改代码的人）
1. 定位 Photoshop
脚本通过 Windows 注册表查找 Photoshop 安装位置（
HKLM\SOFTWARE\Adobe\Photoshop\<版本号>
下的 ApplicationPath），找不到再兜底扫描常见安装目录。
2. 控制 Photoshop：COM + ExtendScript
Python 通过
win32com.client
连接
Photoshop.Application
，然后用
DoJavaScript()
向 PS 发送 ExtendScript 脚本，实现选区、填充、保存。

4. 水印定位
文字水印：OCR（rapidocr_onnxruntime）识别文字框

五、踩坑记录（给同样被 PS 自动化坑过的人）
这套流程里踩过的坑，全部记录在 SKILL.md 里，这里挑几个最经典的：
坑 1：fill 命令报 8800「命令'填充'当前不可用」
两个原因：
文档是
索引色模式
（IndexedColor，枚举值 2）——PS 打开部分 PNG 会这样，必须转 RGB
用了老教程里的
putReference
写法——官方写法不需要 reference，直接
putEnumerated(using,...)
坑 2：右下角选区必须延伸到图片底部
即梦水印下方的缎带高光会一直延伸到图片下边缘。如果选区只框到文字底部，高光会残留一大片（实测白色像素 ~11000）。
选区要取到
(x0-220, y0-110, 图片宽, 图片高)
。
坑 3：cv2.imwrite 不支持中文路径
保存对比图时用
cv2.imwrite
会
静默失败
（不报错但文件没写出来）。必须用 PIL 的
Image.save()
。
