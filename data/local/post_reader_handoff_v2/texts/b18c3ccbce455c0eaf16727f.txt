独家获悉，
AI 基础设施公司基元律动（TokenRhythm）近日完成新一轮融资，截至目前累计融资金额达数千万美金。
本轮融资由弘晖基金领投，聚合资本、尚势资本等机构参与。此前，公司已完成由 Granite Asia 领投，鼎晖 VGC、元璟资本、无限基金参与的种子轮融资。
在技术战略上，基元律动押注的赛道是大模型与应用之间的全新基础设施层 ——
Routing Harness
（智能路由与调度底座）。伴随着大模型数量的爆发，各家模型在能力、价格和适用场景上加速分化，行业的关注点正在从“哪个模型能力最强” 转向“多模型协同如何优化”。如何根据任务阶段动态选择、切换模型，在保障效果的同时控制调用成本，成为 Agent 落地的核心痛点。
同时，基元律动认为，Routing Harness 的价值并不止于“把模型连起来”或降低调用成本。随着越来越多真实任务通过 Routing Harness 在不同模型之间流转，任务执行过程中的模型选择、调用结果与用户反馈，也将沉淀为真实的多模型任务，并进一步反哺模型能力。
基元律动希望以此为基础，从 Routing Harness 进一步走向
Agent-Native Model
，探索面向真实 Agent 任务的新一代模型形态。
这一赛道正成为全球科技巨头关注的 AI 流量新入口。2026 年 8 月，海外支付巨头 Stripe 刚以约 75 亿美元的价格收购了全球最大大模型路由平台 OpenRouter。该平台在同年 5 月估值仅为 13 亿美元，因流量暴增获得巨额溢价；其背后的早期及 B 轮投资方阵容极为豪华，包括了 a16z、红杉资本，以及英伟达与谷歌母公司 Alphabet。
基元律动背后的班底同样不一般，出自华为系
。基元律动 CEO 王云鹤为前华为诺亚方舟实验室主任、盘古大模型负责人。
首席技术官（CTO）韩凯是前华为诺亚方舟实验室首席研究员，与王云鹤是老搭档。公司核心团队成员多来自华为盘古、头部大模型厂商与全球顶尖云服务企业。他们非常擅长解构复杂的 Agent 业务场景，并将其精准转化为多模型协同的底层路由算法。
基元律动的 Routing Harness 面向的是
生产力工具
，让
个人和
企业
开发者
能够根据任务类型、执行阶段与成本约束，自动选择、组合与智能切换最适合的模型，让 Agent 以极低的调用成本完成更复杂的任务。
公司首款开源 AI Agent 产品
OpenSquilla
已斩获超 6600 个 GitHub Stars，其内置的自研 Routing Harness 能力，可以让多模型协作以更低成本实现更高效率。
在 DRACO 复杂研究任务评测中，基元律动凭借一套“国产多模型集成方案”，以 1/3 的成本，超越了海外顶级模型 Fable 5。
另外，基元律动近期上线了多模型聚合 API 平台
TokenRhythm API
，支持 OpenAI、Claude协议。目前，已累计吸引 5.4 万名用户，单日 Token 调用量突破 5000 亿。
基元律动 CEO 王云鹤表示，模型能力只是 Agent 的一部分，如何组织模型、理解真实任务，并让真实使用反馈持续反哺模型，可能是下一阶段整个 Agent 行业需要解决的问题。
